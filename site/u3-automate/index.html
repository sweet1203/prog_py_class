한국반도체 재무팀 이야기 (222쪽)
재무팀은 매일 대량으로 쏟아지는 금융·재무 PDF 문서에서 필요한 내용을 추출해 보고서를 만들어요. PDF를 한글 문서로 바꾸고, 문서 속 표를 스프레드시트로 옮기는 일을 날마다 되풀이하지요. "좀 더 효율적으로 일할 방법이 없을까?" 그래서 PDF 변환 처리 프로그램을 직접 개발해 보기로 했어요.

오늘은 산업 현장의 개발 절차를 따라 기획(요구 분석) → 설계 → 구현 시작까지 함께 밟아 봐요. 코드는 웹에서 돌리지 않고, 읽기용 코드 카드와 다이어그램으로 구조를 읽어요.

기획 · 요구 분석

교과서 222~223쪽 · 개발 절차, 요구 분석 명세서(표Ⅲ-8)

📋 한국반도체 요구 분석 명세서 (223쪽 표Ⅲ-8)

목적은 재무팀의 업무 효율성 향상, 범위는 특정 페이지 PDF를 한글 문서로 바꾸고 표 데이터를 스프레드시트로 바꾸는 것이에요. 핵심 기능은 세 가지예요.

기능 1PDF 문서에서 특정 페이지를 PDF 문서로 추출 및 저장
기능 2추출된 PDF 페이지를 한글 문서(HWPX)로 변환하여 저장
기능 3추출된 PDF 페이지의 표 데이터를 스프레드시트(XLSX)로 변환하여 저장

성능 요구 · 실행 요청 후 2초 이내에 추출·변환하고, 변환된 한글 문서와 스프레드시트는 원본의 내용을 그대로 유지해야 해요. 제약 · 보안상 사외에서는 사용을 제한해요.

🔄 PDF vs HWP (223쪽 Tip)

두 문서 형식은 쓰임이 달라요. 카드를 눌러 특징을 확인해요.

02

설계 · 클래스와 모듈

교과서 224~225쪽 · 개념 설계, 클래스 다이어그램, 모듈화

쉽게 말하면요구 분석 명세서를 어떻게 만들지로 바꾸는 단계예요. 큰 일을 역할이 다른 작은 덩어리(모듈·클래스)로 나누면, 만들기 쉽고 고치기도 쉬워요. 이렇게 나누는 것을 모듈화라고 해요.

🧩 개념 설계 (224쪽)

객체를 개념적으로 다음과 같이 나누어 설계해요. GUI가 사용자와 만나고, 처리 관리자가 전체 흐름을 지휘하며, PDF 추출기와 파일 변환기가 실제 일을 해요.

GUI · 처리 관리자화면을 띄우고, 추출·변환 작업을 순서대로 호출해 관리
PDF 페이지 추출기원본에서 특정 페이지만 뽑아 새 PDF로 저장
파일 변환기추출한 PDF를 HWPX 변환기·Excel 변환기로 바꿔 저장

📐 클래스 다이어그램 (224쪽)

클래스의 속성(+)과 메서드(+( ))를 그림으로 설계해요. ProcessGUI가 process_handler( ) 함수를 부르고, 그 함수가 PDFPageExtractor와 FileConverter를 차례로 호출해요.

속성 앞의 +는 공개(public) 멤버를 뜻해요. FileConverter의 두 메서드는 객체를 만들지 않고 바로 쓰는 정적 메서드예요(03에서 코드로 만나요).

📦 모듈화와 호출 흐름 (224~225쪽)

세 클래스와 process_handler( )를 pdf_tool이라는 꾸러미의 여러 .py 모듈로 나눠요. 실행은 main.py에서 시작해 아래 순서로 이어져요.

main.py가 GUI를 띄우면 → gui.py의 run_processing( )이 → process_handler.py를 호출하고 → 그 안에서 pdf_extractor.py(추출)와 file_converter.py(변환)를 불러요. 완성된 파일 경로는 다시 GUI 화면에 표시돼요.

03

UI 설계 · 구현 시작

교과서 225~227쪽 · GUI 레이아웃, process_handler·pdf_extractor, 라이브러리

쉽게 말하면사용자가 직접 만지는 화면(GUI)을 먼저 그려 두고, 설계한 클래스를 코드로 옮기기 시작해요. 아래 코드는 웹에서 실행할 수 없는 라이브러리를 쓰므로, 읽으며 구조를 이해하는 코드 카드로 보여 줘요.

🖥️ GUI 레이아웃 설계 (225쪽 그림Ⅲ-9)

원본 PDF 선택 · 추출할 페이지 입력 · 저장 폴더 선택 · 변환 실행 버튼과, 결과 경로를 보여 주는 텍스트 영역으로 구성해요.

버튼을 누르면 이벤트가 발생해 정해진 메서드(load_pdf·select_folder·run_processing)가 호출돼요.

🧭 process_handler.py (227쪽) · 읽기용

추출과 변환을 순서대로 호출하는 함수형 모듈이에요. 저장 경로와 파일명을 정한 뒤, 추출기와 변환기의 메서드를 차례로 불러요.

import os                                   # 파일 경로를 다루는 os 모듈
from pdf_extractor import PDFPageExtractor    # PDF 페이지 추출 모듈
from file_converter import FileConverter      # 변환 기능 모듈

def process_handler(pdf_path, save_directory, page_number):
    """PDF 페이지를 추출하고, 한글 문서 및 스프레드시트로 변환"""
    pdf_output   = os.path.join(save_directory, '추출된_페이지.pdf')
    hwpx_output  = os.path.join(save_directory, '변환된_파일.hwpx')
    excel_output = os.path.join(save_directory, '표_데이터.xlsx')

    pdf_extractor = PDFPageExtractor(pdf_path)
    extracted_pdf = pdf_extractor.extract_page(page_number, pdf_output)
    FileConverter.convert_to_hwpx(extracted_pdf, hwpx_output)
    FileConverter.extract_tables_to_excel(extracted_pdf, excel_output)
    return pdf_output, hwpx_output, excel_output   # 세 파일의 경로 반환

📄 pdf_extractor.py (227쪽) · 읽기용

PDFPageExtractor 클래스예요. 원본 PDF를 열어 두었다가, extract_page( )로 특정 페이지만 뽑아 새 PDF로 저장해요.

import pymupdf                      # PDF 처리 라이브러리

class PDFPageExtractor:
    def __init__(self, pdf_path):
        self.pdf_path = pdf_path
        self.reader = pymupdf.open(pdf_path)   # PDF 파일 열기

    def extract_page(self, page_number, output_path):
        """PDF에서 특정 페이지를 추출하여 새 PDF 파일로 저장"""
        new_pdf = pymupdf.open( )               # 빈 PDF 객체 생성
        new_pdf.insert_pdf(self.reader,
                           from_page=page_number + 1, to_page=page_number + 1)
        new_pdf.save(output_path)               # 추출된 PDF 저장
        new_pdf.close( )
        return output_path

클래스는 속성(데이터)과 메서드(기능)를 묶은 설계도예요. self는 그 객체 자신을, __init__은 객체를 만들 때 처음 한 번 실행되는 메서드예요.

🧰 필요한 라이브러리 (227쪽 Tip)

구현에 필요한 라이브러리를 설치해 모듈별로 쓴다고 했어요. 카드를 눌러 각 역할을 확인해요.

💡 도큐먼트 문자열(docstring) · 함수나 클래스의 설명을 """ """로 감싸 적어 두면, 문서화·자동화 도구가 그 설명을 활용할 수 있어요. 코드 동작을 짧게 적는 # 주석과는 쓰임이 조금 달라요.

마무리

핵심 문장 · 마무리 퀴즈 · 생각 정리 질문폼

산업 현장의 개발은 요구 수집·분석 → 설계 → 구현 → 테스트 순서로 진행된다. 사용자의 요구를 정리한 요구 분석 명세서는 사용자와 개발자의 약속이 된다.
설계는 큰 일을 역할이 다른 모듈·클래스로 나누는 모듈화로 한다. PDF 변환 프로그램은 ProcessGUI·process_handler( )·PDFPageExtractor·FileConverter로 나뉘어 main.py → gui.py → process_handler.py → pdf_extractor.py·file_converter.py 순으로 호출된다.
구현은 설계를 코드로 옮기는 단계다. GUI는 tkinter, PDF 처리는 pymupdf, 한글 변환은 pyhwpx, 표 데이터는 pandas 라이브러리를 쓴다. 함수·클래스 설명은 docstring(""" """)으로 적는다.
