01

입출력 기능의 이해

교과서 73쪽 · 입력과 출력, 입력 장치와 출력 장치

쉽게 말하면프로그램이 바깥에서 데이터를 받아들이는 것이 입력, 처리한 결과를 바깥으로 보여 주는 것이 출력이에요. 입력과 출력은 프로그램이 사람과 소통하는 통로예요.

↔️ 입력과 출력이란?

컴퓨터 프로그램은 보통 데이터를 받아서 처리하고 결과를 보여 주는 형태로 동작해요. 외부에서 데이터를 전달받는 것을 입력, 처리 결과를 외부로 표현하는 것을 출력이라고 해요.

⌨️ 입력사용자가 준 데이터를 프로그램이 받아들이는 것
→
⚙️ 처리받은 데이터로 계산·판단 등 필요한 일을 하는 것
→
🖥️ 출력처리한 결과를 화면 등으로 보여 주는 것

입력이 없으면 프로그램은 늘 똑같은 동작만 하고, 출력이 없으면 결과를 확인할 수 없어요. 그래서 둘 다 꼭 필요해요.

🖱️ 입력 장치와 출력 장치 (73쪽 표Ⅱ-1)

데이터를 컴퓨터 안으로 전달하면 입력 장치, 컴퓨터의 결과물을 밖으로 보여 주면 출력 장치예요. 아래 장치를 알맞은 쪽으로 보내 봐요.

▶ 직접 해 보기 · 두 수의 합 (73쪽)

두 수를 입력받아 더한 결과를 출력하는 프로그램이에요. 입력값 칸의 숫자를 바꿔 가며 ▶ 실행해 봐요.

int( )는 입력받은 글자를 정수로 바꿔 줘요. 왜 필요한지는 03에서 자세히 만나요.

02

출력 함수 print( )

교과서 74·77쪽 · print( )의 사용, 이스케이프 문자

쉽게 말하면print( )는 괄호 안의 내용을 화면에 보여 주는 함수예요. 글자는 따옴표로 감싸고, 여러 값은 콤마( , )로 구분해요. 숫자는 연산자와 함께 쓰면 계산한 결과가 나와요.

🖨️ print( )로 출력하기 (74쪽)

글자는 작은따옴표(')나 큰따옴표(")로 감싸요. 콤마로 여러 값을 한 줄에 출력하고, 숫자는 그대로 계산돼요. 실행해서 결과를 확인해 봐요.

함수 · 특정한 기능을 수행하도록 명령어들을 묶어 놓은 것이에요. 콘솔 화면 · 글자로 입력과 출력이 이루어지는 화면으로, 위 실행 결과 칸이 바로 그 역할을 해요.

↩️ 이스케이프 문자 (77쪽)

줄을 바꾸거나 특수 문자를 나타낼 때 역슬래시(\)로 시작하는 이스케이프 문자를 써요. 카드를 눌러 뜻을 확인해요.

※ 역슬래시(\)는 글꼴에 따라 원화(₩)로 보이기도 해요. 같은 문자예요.

\t(탭)과 \n(줄 바꿈)으로 표처럼 정렬해 출력해 봐요. 숫자나 글자를 바꿔 ▶ 실행해 결과가 어떻게 달라지는지 봐요.

💡 end와 sep (77쪽 Tip) print(..., end=' ')는 출력 끝의 줄 바꿈을 공백으로 바꿔 다음 출력과 이어 쓰게 해요. print(..., sep='-')는 여러 값 사이의 구분자를 공백 대신 대시(-)로 바꿔요.

03

입력 함수 input( )과 형 변환

교과서 78·79쪽 · input( ), 자료형 변환, split( )

쉽게 말하면input( )은 키보드로 값을 받는 함수예요. 그런데 받은 값은 언제나 문자열(글자)로 저장돼요. 그래서 숫자로 계산하려면 int( )(정수)나 float( )(실수)로 바꿔 줘야 해요.

⌨️ input( )으로 값 받기 (78쪽)

괄호 안의 글은 입력 커서 앞에 안내로 보여 줘요. 받은 값은 변수에 저장해 써요. 입력값 칸에 이름과 나이를 넣고 실행해 봐요.

함수하는 일
int( )정수형으로 변환
float( )실수형으로 변환
str( )문자열형으로 변환
type( )자료형을 알려 줌

🔁 형 변환이 왜 필요할까? (79쪽)

두 값을 입력받아 더해 봐요. 입력값은 문자열이라, 그대로 더하면 숫자가 아니라 글자가 이어 붙어요('12' + '34' → 1234). 실행해서 확인해 봐요.

이번엔 int( )로 바꿔서 더해 봐요. 같은 입력이라도 결과가 달라져요.

✂️ 한 번에 여러 값 받기 · split( ) (78쪽 Tip)

split( )은 입력한 문자열을 공백 기준으로 나눠 줘요. 이름과 나이를 한 줄에 띄어 적어 받아 봐요.

04

서식 지정과 활용

교과서 76·80·81쪽 · f-문자열, 정렬 서식, 영수증 출력

쉽게 말하면값이 바뀌어도 같은 틀로 깔끔하게 출력하려면 서식(형식)을 지정해요. 가장 많이 쓰는 방법이 f-문자열이에요. 문자열 앞에 f를 붙이고, 넣고 싶은 값을 중괄호 { }에 적어요.

🏷️ f-문자열로 값 끼워 넣기 (76쪽)

출력 형식을 지정하는 방법은 % 연산자, format( ) 함수, f-문자열 세 가지예요. 아래 세 줄은 모두 같은 결과를 내요. 값을 바꿔 실행해 봐요.

📐 자릿수와 정렬 맞추기 (81쪽)

중괄호 안에 :를 쓰고 규칙을 적으면 자릿수·정렬을 맞출 수 있어요. 숫자 10은 전체 칸 너비예요.

서식뜻
{x:>10}너비 10칸, 오른쪽 정렬
{x:<10}너비 10칸, 왼쪽 정렬
{x:^10}너비 10칸, 가운데 정렬
{n:0.0f}소수점 아래 0자리(반올림)
{n:<8,}너비 8칸·왼쪽 정렬·천 단위 쉼표

정렬이 어떻게 달라지는지 직접 봐요.

🧾 활용 · 회전 초밥 영수증 (81쪽 해 보기 5)

접시 색마다 가격이 달라요. 색깔별 접시 개수를 입력받아, 정렬 서식으로 영수증처럼 출력해요. 입력값(빨강·노랑·파랑·초록 개수)을 바꿔 실행해 봐요.

총 가격 줄이 깔끔하게 맞춰지는 건 :<8(너비 8칸·왼쪽 정렬)과 :<8,(천 단위 쉼표) 덕분이에요.
