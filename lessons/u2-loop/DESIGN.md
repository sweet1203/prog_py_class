**교과서에서 보정한 점**
- 140쪽 소수 판별: 교과서 코드는 `num=2`일 때 `range(2,2)`가 비어 `i`가 정의되지 않아 NameError. 실행 확인 후 04 캡션으로 안내(코드는 교과서 그대로).
- 132쪽 `i += 1` 누락(무한 반복)은 읽기용 `<pre class="code">`로만 제시(실행 금지).
- 139쪽 숫자 맞히기(`while num != com`·`random`)는 실행하지 않고, 정답 7 고정·`for` 최대 5회·`break`로 바꾼 변형을 pyrun에 넣음(변형임을 화면에 명시). 원본은 읽기 안내만.
- 133쪽 해 보기 6은 pack 소스 파일(`start += 2`, `while start <= end`)로 빈칸을 채워 제시.
- 139쪽 해 보기 8-1 역삼각형은 소스 파일 코드 그대로(`range(3, i-1, -1)`).
- 144쪽 수행 활동 4(`gTTS`·`!pip`·IPython)는 웹 실행 불가·정답성 과제라 코드·메뉴 표 미포함. 설계(메모·chips)만 두고 읽을거리로 소개.
- 137쪽 리스트 내포·141쪽 TTS 예제 11·143쪽 모듈/패키지/라이브러리는 이 차시 범위(반복문 핵심)에서 제외.
- 145쪽 「핵심 정리」·성취도 평가 문장은 베끼지 않고 카드·sorter·key3로 새로 풀어 씀.
