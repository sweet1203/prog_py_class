01

알고리즘의 제어 구조

교과서 38쪽 · 그림Ⅰ-15 순차·선택·반복

쉽게 말하면알고리즘은 세 가지 틀, 즉 순차(차례대로) · 선택(조건에 따라 갈라짐) · 반복(조건을 만족하는 동안 되풀이)을 조합해서 작성해요. 이 세 가지를 제어 구조라고 불러요.

🧭 세 가지 제어 구조 (38쪽 그림Ⅰ-15)

알고리즘의 모든 과정은 명확하고 구체적으로, 모든 경우의 수를 고려해 실현 가능하도록 작성해요. 일반적으로 아래 세 가지 형태를 이용해요.

순차 구조

처리 절차를 순서대로 실행하는 알고리즘

예 · 청소하기 (먼지를 턴다 → 청소기를 돌린다 → 바닥을 닦는다)

선택 구조

조건식의 만족 여부에 따라 분기해 실행하는 알고리즘

예 · 나이 > 18 이면 성인 요금, 아니면 청소년 요금

반복 구조

조건식을 만족하는 동안 같은 명령을 되풀이하는 알고리즘

예 · 잔액 >= 1000 인 동안 음료 선택 되풀이

제어 구조를 활용한 실제 프로그래밍(제어문)은 Ⅱ단원에서 자세히 배워요. 지금은 세 틀로 흐름을 그리는 법에 익숙해지면 돼요.

🎮 장면을 보고 제어 구조 고르기

아래 장면이 순차·선택·반복 중 어느 구조인지 골라 봐요. 「순서대로인지」, 「조건에 따라 갈라지는지」, 「조건을 만족하는 동안 되풀이하는지」를 살펴봐요.

02

정수의 합 구하기

교과서 39~40쪽 · 그림Ⅰ-16·17 · 반복 구조와 공식

쉽게 말하면같은 문제도 여러 방법으로 풀 수 있어요. 1부터 차례로 더하는 반복으로도, 한 번에 구하는 공식으로도 합을 구할 수 있지요. 공식은 반복이 없어 더 빨라요.

➕ 예제 1 · 1부터 10까지의 합 (39쪽 그림Ⅰ-16)

sum에 1부터 10까지를 차례로 더해요. 아래 순서도(반복 구조)를 의사 코드로 적으면 이래요.

sum = 0, i = 1
i <= 10 인 동안 반복:
    sum = sum + i
    i = i + 1
sum 출력        # 결과 55

버튼을 눌러 반복을 한 번씩 실행하며 i와 sum이 어떻게 바뀌는지 따라가 봐요.

⚡ 예제 2 · 1부터 n까지의 합 (더 빠른 방법) (40쪽 그림Ⅰ-17)

반복으로 하나하나 더하는 대신, 가우스의 덧셈 공식으로 한 번에 구할 수 있어요.

sum = (1 + n) * n / 2
sum 출력

1부터 100까지라면 101 × 100 ÷ 2 = 5050 이지요. 일반식으로는 n × (n + 1) ÷ 2 예요. 반복 횟수가 없어 실행 속도가 빨라요.

같은 문제라도 더 간단하고 빠른 방법을 찾는 것이 알고리즘 설계의 중요한 일이에요.

03

그리디 알고리즘 · 거스름돈

교과서 41쪽 · 그림Ⅰ-18·19 · 최소 동전 개수

쉽게 말하면그리디(욕심쟁이) 알고리즘은 매 순간 지금 가장 좋아 보이는 것을 고르는 방법이에요. 거스름돈을 큰 동전부터 최대한 많이 주면, 동전 수가 가장 적어져요.

🪙 거스름돈 최소 동전 구하기 (41쪽)

그리디 알고리즘은 현재 상황에서 가장 최적의 답을 선택하는 알고리즘이에요. 거슬러 줄 돈 n원(10의 배수)을 500·100·50·10원 동전으로 줄 때, 가장 큰 금액부터 최대한 나눠 주면 필요한 동전 수가 가장 적어요.

count = 0, i = 0
n 입력
coin = [500, 100, 50, 10]
i < 4 인 동안 반복:
    count = count + n / coin[i]   # 몫(개수)
    n = n % coin[i]               # 나머지(남은 돈)
    i = i + 1
count 출력

금액을 정하고 「다음 동전 ▶」을 눌러 큰 동전부터 개수를 세어 봐요.

⚠️ 그리디가 늘 최선은 아니에요 (41쪽) 만약 동전이 coin = [500, 400, 100, 50, 10] 처럼 있다면, 800원을 그리디는 500원 1개 + 100원 3개 = 4개로 줘요. 하지만 400원 2개면 2개로 끝나죠. 그리디는 매 순간 최적을 고르지만 전체적으로 가장 좋은 결과를 늘 보장하지는 않아요. 다행히 우리나라 동전은 큰 동전이 작은 동전의 배수라, 거스름돈 문제에 그리디를 써도 가장 적은 개수가 나와요.

04

정렬과 탐색

교과서 42~43쪽 · 그림Ⅰ-20 버블 정렬 · 그림Ⅰ-21 이진 탐색

쉽게 말하면정렬은 데이터를 정해진 순서로 나열하는 것, 탐색은 원하는 데이터를 찾는 것이에요. 학교에서 학생을 키·이름 순으로 줄 세우거나(정렬), 명렬표에서 한 사람을 찾는(탐색) 일과 같아요.

📊 정렬 · 오름차순과 내림차순 (42쪽)

오름차순가장 작은 값을 앞에 두고 뒤로 갈수록 값이 커지도록 정렬예 · 1, 2, 3, 4, 5 / 가, 나, 다, 라
내림차순가장 큰 값을 앞에 두고 뒤로 갈수록 값이 작아지도록 정렬예 · 5, 4, 3, 2, 1 / 라, 다, 나, 가

버블 정렬은 서로 이웃한 두 데이터를 비교해, 더 큰 값을 뒤쪽으로 보내는 과정을 되풀이하는 정렬 방식이에요.

score = [100, 83, 92, 88, 96]
i = 0 ~ len(score)-1 반복:
    j = 0 ~ len(score)-2 반복:
        score[j] > score[j+1] 이면
            score[j] 와 score[j+1] 의 자리를 바꾼다
score 출력

5명의 점수(100, 83, 92, 88, 96)를 오름차순으로 정렬해요. 버튼으로 한 비교씩 따라가 봐요. (노란 막대는 지금 비교 중, 초록 막대는 자리가 정해진 값)

🔍 탐색 · 순차 탐색과 이진 탐색 (43쪽)

순차 탐색처음부터 하나씩 차례대로 비교하며 찾는 방식정렬되지 않은 데이터에서도 가능
이진 탐색정렬된 데이터에서 중간값을 기준으로 절반씩 줄여 가며 빠르게 찾는 방식정렬된 데이터에서만 사용 가능

오름차순으로 정렬된 7명의 점수에서 95점을 이진 탐색으로 찾아요.

score = [83, 86, 88, 92, 95, 96, 100]
target = 95
start = 0, end = len(score) - 1
start <= end 인 동안 반복:
    mid = (start + end) // 2
    score[mid] == target 이면 break
    score[mid] > target 이면 end = mid - 1
    아니면 start = mid + 1
mid 출력

「다음 ▶」을 눌러 범위가 절반씩 줄어드는 과정을 따라가 봐요.

06

마무리 · Ⅰ단원 3절 정리

핵심 문장 · 알고리즘 정리 · 마무리 퀴즈 · 질문폼

알고리즘은 순차·선택·반복 세 가지 제어 구조로 작성한다. 순차는 차례대로, 선택은 조건에 따라 갈라지고, 반복은 조건을 만족하는 동안 같은 명령을 되풀이한다.
같은 문제도 여러 방법으로 풀 수 있다. 1부터 n까지의 합은 반복으로도, 공식 (1+n)×n÷2로도 구할 수 있고 공식이 더 빠르다. 그리디는 매 순간 최적을 고르는 방법으로, 거스름돈을 큰 동전부터 주면 동전 수가 가장 적어진다(늘 최적을 보장하지는 않는다).
정렬은 데이터를 순서대로 나열하는 것(버블 정렬은 이웃한 두 값을 비교해 교환), 탐색은 원하는 데이터를 찾는 것(이진 탐색은 정렬된 데이터에서 절반씩 줄이며 찾는다).
