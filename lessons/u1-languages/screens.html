01

프로그램이란?

교과서 15~16쪽 · 프로그래밍 과정, 프로그램과 소프트웨어

쉽게 말하면프로그램은 컴퓨터에게 「이 순서로, 이렇게 해라」라고 알려 주는 명령어들의 묶음이에요. 사람이 프로그래밍 언어로 이 명령을 적는 전 과정을 프로그래밍이라 하고, 그 일을 하는 사람이 프로그래머예요.

🔄 프로그래밍 과정 (15쪽 그림Ⅰ-2)

프로그램은 프로그래머가 프로그래밍 언어로 명령을 적는 프로그래밍 과정을 통해 만들어져요.

🧑‍💻 프로그래머프로그램의 알고리즘을 설계하고 프로그램을 개발하는 전문가

→
📦 프로그램컴퓨터가 처리할 순서와 방법을 지시하는 명령어들의 집합

코딩이란? 프로그래밍 언어로 작성된 문서를 흔히 코드(code)라 하고, 이 코드를 작성하는 일을 코딩(coding)이라고 해요.

🧱 프로그램 · 소프트웨어 · 앱, 어떻게 다를까? (16쪽)

소프트웨어는 컴퓨터를 더 효율적으로 운영하기 위해 만든 프로그램을 통틀어 가리키는 더 넓은 말이에요. 소프트웨어는 두 가지로 나뉘어요.

시스템 소프트웨어컴퓨터 하드웨어를 제어하고 접근할 수 있도록 설계된 소프트웨어예 · 운영체제(윈도, 맥OS, 리눅스, 안드로이드, iOS)
응용 소프트웨어운영체제가 주는 자원과 인터페이스를 활용해 사용자가 특정 작업을 직접 하도록 돕는 소프트웨어예 · 문서 작성, 이미지 편집, 게임 등

우리가 말하는 프로그램은 대체로 응용 소프트웨어에 속하고, 소프트웨어라는 더 넓은 개념 안에 들어가요. 스마트폰이나 태블릿에서 쓰는 소프트웨어는 흔히 애플리케이션(application) 또는 앱(app)이라고 불러요.

🃏 용어 카드 뒤집기

카드를 눌러 낱말의 뜻을 확인해요. 뜻을 먼저 떠올려 본 뒤 뒤집으면 더 잘 외워져요.

💡 4차 산업혁명의 핵심은 소프트웨어 (16쪽 「정보」) 자동차가 「가솔린이 아니라 소프트웨어로 움직인다」는 말이 나올 만큼, 차의 주요 기능이 소프트웨어로 돌아가는 자동차(SDV, Software Defined Vehicle)가 등장했어요. 인공지능(AI)·사물 인터넷(IoT)·로봇·빅데이터의 발전과 함께, 소프트웨어는 산업 전반에 혁신을 일으키는 핵심 동력으로 꼽혀요.

02

프로그램의 실행 원리

교과서 17쪽 · 하드웨어와 소프트웨어, 프로그램 실행 과정

쉽게 말하면소프트웨어는 혼자서는 아무 일도 못 해요. 실제 기계인 하드웨어를 통해서만 실행돼요. 반대로 하드웨어도 소프트웨어가 없으면 아무 기능을 못 하지요. 둘은 서로 꼭 필요한 짝이에요.

🏗️ 하드웨어와 소프트웨어의 관계 (17쪽 그림Ⅰ-3)

사용자부터 하드웨어까지, 아래로 내려갈수록 기계에 가까워져요. 위층은 아래층의 도움을 받아 움직여요.

🙋 사용자소프트웨어를 설치하고 실행시켜 다양한 하드웨어를 원하는 대로 이용하는 주체
🖌️ 응용 소프트웨어사용자가 하고 싶은 작업을 마음껏 하도록 지원하는 소프트웨어
🧰 시스템 소프트웨어컴퓨팅 시스템을 구성하는 하드웨어를 올바르게 제어하는 소프트웨어
🔩 하드웨어소프트웨어에게 지시받은 특정한 일을 수행하도록 제작된 전자 장치

⚙️ 프로그램의 실행 과정 (17쪽 그림Ⅰ-4)

「2 더하기 3」을 계산하는 프로그램을 예로, 실행되는 순서를 버튼으로 하나씩 밝혀 봐요.

휘발성 · 전원이 차단되면 저장된 데이터가 사라지는 성질이에요. 주기억 장치(RAM)는 휘발성이라, 프로그램 결과를 오래 보존하려면 보조 기억 장치에 다시 저장해야 해요.

03

프로그래밍 언어의 분류

교과서 18~21쪽 · 세 가지 기준, 컴파일과 인터프리트

쉽게 말하면프로그래밍 언어는 아주 많아서, 보는 기준에 따라 여러 갈래로 나눠요. ①기계·사람 중심(저급·고급) ②설계 방법(절차지향·객체지향) ③개발 분야·목적(시스템·응용·교육용), 이렇게 세 기준을 하나씩 만나 봐요.

🗂️ 세 가지 분류 기준 (18쪽 표Ⅰ-1)

① 기계와 사람 중심저급 언어 · 고급 언어
② 설계 방법절차지향 언어 · 객체지향 언어
③ 개발 분야·목적시스템 · 응용 · 교육용 프로그래밍 언어

같은 언어라도 기준이 다르면 서로 다른 칸에 들어가요. 예를 들어 파이썬은 고급이면서 객체지향이고, 응용(웹·인공지능 등) 개발에 쓰여요.

① 기계와 사람 중심 · 저급 언어와 고급 언어 (19쪽)

컴퓨터는 사람의 자연어를 이해하지 못해요. 그래서 컴퓨터에 얼마나 가까운 언어인가로 나눠요.

저급 언어 기계어 · 0과 1로 이루어진 2진 코드로 하드웨어를 직접 제어해요. 번역 없이 바로 실행되어 빠르지만, 사람이 이해하기 매우 어려워요. 어셈블리어 · 기계어를 사람이 읽기 쉬운 명령어로 1:1 대응시킨 언어예요. 어셈블러라는 번역 프로그램으로 기계어로 바꿔 실행해요.
고급 언어 사람이 쓰는 자연어와 비슷한 형태라 하드웨어를 깊이 몰라도 작성하기 쉬워요. 컴퓨터가 이해하도록 컴파일러나 인터프리터 같은 번역 프로그램으로 기계어로 바꿔야 실행돼요. 예 · C, Java, Python 등

🌐 번역 프로그램 · 컴파일 vs 인터프리트 (19쪽 「정보」)

고급 언어로 짠 소스 코드를 기계어로 바꾸는 방법은 두 가지예요. 버튼을 눌러 비교해 봐요.

② 설계 방법 · 절차지향과 객체지향 (20쪽 표Ⅰ-2)

자전거 만들기로 비교해 봐요. 같은 자전거라도 만드는 방식이 달라요.

🚲 절차지향 언어 자전거를 만들려고 프레임을 만들고 핸들·안장을 조립하고 바퀴를 다는 등, 제작 과정을 순서대로 하나하나 수행해 완성해요. 단계에 따라 순서대로 처리 · 데이터와 함수를 따로 다룸 · C, Fortran, Basic 등
🛠️ 객체지향 언어 자전거를 핸들·안장·바퀴 같은 부품(객체) 단위로 나눠 각각의 기능을 정하고, 이들을 조합해 완성해요. 객체 중심으로 프로그래밍 · 코드 재사용·생산성·유지 보수에 유리 · Java, C++, C#, Python 등

아래 카드를 읽고 절차지향인지 객체지향인지 골라 봐요. 「순서대로 하나하나」인지, 「부품(객체)으로 나눠 조합」인지를 살펴봐요.

③ 개발 분야·목적에 따른 분류 (21쪽)

시스템 프로그램 개발 언어운영체제·유틸리티처럼 컴퓨터의 기본 동작을 지원하는 프로그램 개발 · C, C++ 등
응용 프로그램 개발 언어웹(JavaScript·PHP·Python 등), 모바일 앱(Kotlin·Swift·Java 등), 게임(C#·C++ 등), 인공지능(Python 등)
교육용 프로그래밍 언어명령을 블록으로 조립하듯 만드는, 초보자를 위한 블록 코딩 언어 · Scratch, Entry, MakeCode 등

05

마무리

핵심 문장 · 마무리 퀴즈 · 생각 정리 질문폼

프로그래머가 프로그래밍 언어로 명령을 적는 프로그래밍 과정을 통해 프로그램이 만들어진다. 프로그램은 보조 기억 장치에 저장되었다가, 실행되면 주기억 장치로 올라와 중앙 처리 장치(CPU)에서 연산되고 결과가 출력된다.
프로그래밍 언어는 보는 기준에 따라 기계와 사람 중심(저급·고급), 설계 방법(절차지향·객체지향), 개발 분야·목적(시스템·응용·교육용)의 세 갈래로 나눌 수 있다.
고급 언어는 기계어로 번역해야 실행된다. 소스 코드 전체를 한꺼번에 번역한 뒤 실행하면 컴파일(C, C++), 실행할 때마다 한 줄씩 번역하며 실행하면 인터프리트(Python, JavaScript 등)이다.
