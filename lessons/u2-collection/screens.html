01

리스트와 튜플

교과서 100·103·109쪽 · 순서(인덱스)가 있는 컨테이너

쉽게 말하면리스트와 튜플은 값을 순서대로 줄 세워 저장해요. 줄마다 0번부터 번호(인덱스)가 붙어서 번호로 꺼낼 수 있어요. 둘의 가장 큰 차이는 저장한 뒤에 요소를 바꿀 수 있느냐예요.

📋 리스트 · 요소를 바꿀 수 있어요

리스트는 [값, 값, ...] 모양으로 만들어요. 인덱스로 꺼내고(인덱싱), 구간을 잘라 오고(슬라이싱), 요소를 새 값으로 바꿀 수 있어요. 결과를 예상해 보고 ▶ 실행해요.

100쪽 · 리스트에 없는 인덱스(예: 길이가 2인 리스트의 a[2])에 접근하면 오류가 나요.

🔒 튜플 · 요소를 바꿀 수 없어요

튜플은 (값, 값, ...) 모양으로 만들어요. 인덱싱·슬라이싱은 리스트와 같지만, 요소 변경은 불가능해요. 주석 줄의 #을 지우고 실행해서 어떤 오류가 나는지 확인해 봐요.

⚖️ 한눈에 비교 (103쪽 정보)

자료형만드는 모양요소 변경순서·인덱싱요소 중복
리스트[값, 값]가능가능허용
튜플(값, 값)불가능가능허용

리스트·튜플처럼 요소가 순서대로 나열된 자료형을 시퀀스 자료형이라고 해요. 둘은 in·not in, len( ), sorted( )도 같이 쓸 수 있어요.

02

딕셔너리

교과서 100·101쪽 · 키와 값, 수정·추가·삭제, 메소드

쉽게 말하면사전에서 낱말(키)을 찾으면 뜻(값)이 나오는 것과 같아요. 딕셔너리는 키와 값을 쌍으로 저장하고, 번호 대신 키로 값을 찾아요.

📖 딕셔너리 만들기 (100쪽)

{키: 값, 키: 값}처럼 콜론(:)으로 키와 값을 묶고, 쉼표로 구분해 중괄호 안에 넣어요. 키는 숫자·문자열·튜플처럼 바꿀 수 없는 자료형만 쓸 수 있고, 키가 같으면 마지막에 넣은 값만 남아요.

키가 문자열이면 따옴표를 붙여야 해요. 딕셔너리는 순서 번호가 없어서 슬라이싱은 쓸 수 없어요.

✏️ 값 수정 · 추가 · 삭제 (100쪽)

키를 이용해 요소를 바꿔요. 있는 키에 값을 넣으면 수정, 없는 키에 넣으면 추가, del을 쓰면 그 키의 요소가 삭제돼요. 실행 전에 결과를 먼저 예상해 봐요.

🍔 직접 해 보기 · 메뉴 가격 관리 (101쪽 해 보기 4)

메뉴와 가격이 저장된 딕셔너리에서 가격 수정·메뉴 추가·삭제를 하고, 가격을 높은 순으로 정렬해요. .values( )는 값만 꺼내고 sorted(..., reverse=True)는 내림차순으로 정렬해요. 가격이나 메뉴 이름을 바꿔 실행해 봐요.

🧰 딕셔너리 메소드 (101쪽 표Ⅱ-5)

메소드하는 일
.keys( )키를 돌려줘요
.values( )값을 돌려줘요
.items( )키와 값을 쌍으로 돌려줘요
.get( )특정 키의 값을 돌려줘요. 키가 없으면 지정한 값(생략하면 None)
.pop( )특정 키의 값을 돌려주고 그 요소를 지워요
.clear( )모든 요소를 지워요

.get( )에 마지막 값을 바꿔 보며 없는 키일 때 무엇이 나오는지 확인해 봐요.

값을 고치거나 추가할 때 update( ) 메소드를 써도 돼요(100쪽 Tip). 예를 들면 a.update({88: 's'})처럼 써요.

03

집합 set

교과서 102·103쪽 · 중복 제거, 교집합

쉽게 말하면집합은 수학의 집합처럼 서로 다른 값을 순서 없이 모아 둔 자료형이에요. 같은 값을 여러 번 넣어도 하나만 남아서 중복 제거에 편리해요.

🧺 집합의 기본 (102쪽)

집합은 {값, 값}으로 만들어요. 값 없이 { }만 쓰면 빈 딕셔너리가 되므로, 빈 집합은 set( )으로 만들어요. 교집합 &, 합집합 |, 차집합 -도 확인해 봐요.

집합은 값의 순서를 유지하지 않아서, 출력되는 순서가 실행 환경에 따라 달라질 수 있어요.

🛒 직접 해 보기 · 쇼핑 목록 비교 (103쪽 해 보기 5)

쇼핑 목록 두 개가 리스트로 있어요. set( )으로 바꿔 중복을 없애고, &로 공통 항목만 구해요. 목록에 항목을 더하거나 빼고 다시 실행해 봐요.

🔧 집합 메소드 (102쪽 표Ⅱ-6)

메소드하는 일
.add( ) · .update( )값 한 개 추가 · 여러 값 추가
.discard( ) · .remove( )값 삭제 · 값 삭제(없으면 오류)
.intersection( )교집합(&와 같아요)
.union( ) · .difference( )합집합(|) · 차집합(-)

04

컬렉션 활용

교과서 104·105쪽 · 단어 목록 만들기, 당첨자 추첨

쉽게 말하면배운 자료형을 이어서 쓰면 문제를 풀 수 있어요. 문장 → 리스트(단어 나누기) → 집합(중복 제거) → 리스트(정렬)처럼 자료형을 바꿔 가며 필요한 기능을 빌려 와요.

📚 영어 단어 목록 만들기 (104쪽 해 보기 6)

영어 문장 세 개에서 단어만 뽑아 중복 없이, 알파벳 순서로 출력해요. 줄마다 어떤 자료형이 되는지 주석을 읽으며 따라가 봐요. 입력값의 문장을 바꿔 실행해도 좋아요.

split( )은 공백 기준으로 나눈 리스트를, set( )은 중복이 없는 집합을, sorted( )는 정렬된 리스트를 돌려줘요.

🎲 당첨자 추첨 (105쪽 해 보기 7)

후보자 5명 중 입력한 수만큼 무작위로 뽑고, 이름순으로 정렬해 출력해요. random.sample(data, n)은 data에서 중복 없이 n개를 뽑아요. 뽑을 당첨자 수(마지막 입력값)를 바꾸고 여러 번 실행해 봐요.

실행할 때마다 결과가 달라지는 것이 정상이에요. 당첨자가 이름순으로 나오는지 확인해 봐요.

⚠️ 교과서 소스 코드 확인 · sort와 sort( )

105쪽 소스 코드에는 winners.sort처럼 괄호 없이 적혀 있어요. 그대로 실행하면 정렬이 되지 않아요. 함수는 괄호를 붙여야 실행돼서, 위 추첨 코드에서는 winners.sort( )로 고쳐 썼어요. 두 줄의 차이를 직접 확인해 봐요.

06

마무리

핵심 문장 · 마무리 퀴즈 · 생각 정리 질문폼

리스트 [ ]와 튜플 ( )은 요소에 0부터 번호(인덱스)가 있어 인덱싱·슬라이싱을 쓸 수 있다. 리스트는 요소를 바꿀 수 있고, 튜플은 바꿀 수 없다.
딕셔너리는 키와 값을 쌍으로 저장하고 키로 값을 찾는다. 키에 값을 넣어 수정·추가하고 del로 삭제하며, 키는 바꿀 수 없는 자료형만 쓴다.
집합은 순서가 없고 같은 값을 하나만 저장한다. set( )으로 중복을 없애고 &로 교집합을 구한다. 자료형을 바꿔 가며 쓰면 문제를 풀 수 있다.
