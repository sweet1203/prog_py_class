- 교과서 100~109쪽 「컬렉션 자료형」(딕셔너리·집합·변수와 자료형의 활용). 본보기 `u2-io`와 같은 틀, 단원색 `#1f9d74` 계열에 화면별 소주제 색(리스트·튜플 파랑, 딕셔너리 초록, 집합 보라, 활용 주황, 스스로 해결 빨강).
- 화면 7개: 시작 → 01 리스트·튜플 → 02 딕셔너리 → 03 집합 → 04 컬렉션 활용 → 05 스스로 해결하기 → 06 마무리.
- pyrun 13개(시작 1, 01에 2, 02에 4, 03에 2, 04에 3, 05에 1 — 그중 05는 아이디어 예시). `input()`은 stdin 미리 채움, 무한 반복 없음.
- 퀴즈: 01=2, 02=3, 03=2, 04=2, 마무리(6)=4 → 13문항. 분류 `sorter` 1개(리스트/튜플/딕셔너리/집합), `chips` 3개.
- 메모 키: planLearn, invFlow, invIdea, typePick, featPick, selfCheckPick, keyQ.

## 확인할 점
- **105쪽 소스 `winners.sort` 괄호 누락**: 교과서·소스 모두 `winners.sort`(괄호 없음)라 정렬이 되지 않는다. pyrun 예시는 `winners.sort()`로 고쳐 넣었고, 화면 04에 `a.sort`와 `a.sort()`를 비교하는 실행 칸을 두었다.
- **리스트·튜플 코드**: pack에 리스트·튜플 「해 보기」 소스가 없다(해당 쪽은 98쪽 이전). 01 화면의 코드는 교과서 103쪽·109쪽 설명(인덱스 0부터, 튜플 요소 변경 불가)을 바탕으로 만든 예시다.
- **108쪽 수행 활동2(재고 관리)**: 정답성 과제라 완성 코드를 넣지 않았다. 실행 결과·`dict.get(키, 0)` 아이디어(급식 투표 예, 다른 맥락)·빈칸 틀만 제시.
- 딕셔너리의 순서: 103쪽 표는 「순서 있음」이나 100쪽 본문은 「순차 저장 아님·슬라이싱 불가」라서, 화면에서는 순서 언급을 피하고 슬라이싱 불가만 적었다.
- 집합 출력 순서는 실행 환경에 따라 달라질 수 있음(102쪽 말풍선 반영).
- 교과서 「주요 개념 정리·성취도 평가」 문장은 그대로 옮기지 않고 다시 썼다.
