01

사각형 그리기

교과서 235쪽 · turtle 모듈의 기초, 반복으로 도형 그리기

쉽게 말하면거북이를 원하는 자리로 옮긴 뒤, 「돌고 → 앞으로」를 네 번 반복하면 사각형이 그려져요. 같은 동작을 여러 번 해야 하니 for 반복이 딱 맞아요.

🧱 사각형 그리기 코드 (235쪽 소스 코드) · 읽기용

아래 코드를 차근차근 읽어 봐요. penup( )으로 펜을 들고 시작 위치로 옮긴 뒤, pendown( )으로 펜을 내리고 for 반복으로 네 변을 그려요.

import turtle
screen = turtle.Screen()
screen.title('사각형 그리기')
screen.setup(400, 400)           # 창 크기 400 × 400 픽셀
t = turtle.Turtle()
t.penup()                        # 펜 올리기(선 그리기 X)
t.goto(100, 100)                 # 처음 위치로 이동
t.shape('turtle')
t.pendown()                      # 펜 내리기(선 그리기 O)
for i in range(0, 4):             # 네 변을 반복
    t.right(90)                  # 오른쪽으로 90도 회전
    t.forward(200)               # 앞으로 200픽셀 이동

웹에서는 turtle 창을 띄울 수 없어, 코드는 읽기용이에요. 대신 오른쪽 아래 그림으로 실행 결과를 확인해요.

🖼️ 실행 결과 (235쪽 터틀 실행 결과)

「90도 회전 → 200픽셀 전진」을 네 번 반복하니 한 변이 200픽셀인 정사각형이 그려져요.

🐢 자리가 goto(100, 100)로 옮긴 시작점이에요. 점선은 펜을 든 채(penup) 이동한 자취라 선이 그려지지 않아요.

사각형 코드에 나온 명령이에요. 카드를 눌러 명령 ↔ 하는 일을 확인해요.

02

겹치는 삼각형

교과서 235쪽 · 중첩 반복으로 도형을 겹쳐 그리기

쉽게 말하면정삼각형 하나를 그리는 반복(안쪽)을, 조금씩 돌려 가며 여러 번 그리는 반복(바깥쪽) 안에 넣으면, 삼각형이 겹쳐지며 꽃 모양이 돼요. 이렇게 반복 안에 반복을 넣는 것을 중첩 반복이라고 해요.

🔺 겹치는 삼각형 코드 (235쪽 소스 코드) · 읽기용

창의 중앙에서 시작해, 120도씩 도는 정삼각형을 60도씩 돌려 가며 6번 겹쳐 그려요.

for i in range(6):             # 삼각형 6개 반복
    for j in range(3):         # 정삼각형 그리기
        t.forward(200)
        t.right(120)
    t.right(60)                  # 다음 삼각형을 60도 돌려 배치

정삼각형은 forward(200) 뒤에 right(120)을 세 번 반복하면 완성돼요(바깥쪽 각 120도 × 3 = 360도).

🖼️ 실행 결과 (235쪽 터틀 실행 결과)

같은 정삼각형 6개가 60도씩 돌아가며 겹쳐, 가운데가 꽉 찬 꽃·별 모양이 돼요.

바깥쪽 반복은 삼각형을 몇 개 배치할지(6번)를, 안쪽 반복은 삼각형 하나를 그리는 일(변 3개)을 맡아요.

03

하트 찍기

교과서 235쪽 · 함수와 점(dot)으로 격자 그림 그리기

쉽게 말하면그림을 작은 점으로 나누어 생각해요. 행·열·개수를 정해 한 줄씩 오렌지색 점을 찍는 일을 heart( ) 함수로 묶어 두고, 줄마다 값을 바꿔 부르면 점들이 모여 하트가 돼요.

🧡 하트 코드 (235쪽 소스 코드) · 읽기용

heart(y, x, n)은 y행 x열에서 시작해 오른쪽으로 20픽셀 간격마다 오렌지색 점을 n개 찍는 함수예요. 아래에서는 10줄을 각각 다른 값으로 불러요.

import turtle
t = turtle.Turtle()
def heart(y, x, n):            # heart 함수 정의
    x = x * 20                   # x좌표를 x * 20으로
    y = -y * 20                  # y좌표를 -y * 20으로
    for i in range(n):          # n번 반복해 점 찍기
        t.goto(x + i * 20, y)    # 점의 위치 설정
        t.dot(20, 'orange')      # 지름 20 오렌지색 점
t.penup()                        # 터틀의 자취는 그리지 않기
heart(0, 1, 2); heart(0, 6, 2); heart(1, 0, 4); heart(1, 5, 4); heart(2, 0, 9)
heart(3, 0, 9); heart(4, 1, 7); heart(5, 2, 5); heart(6, 3, 3); heart(7, 4, 1)

함수로 묶으면, 같은 「점 찍기」 동작을 값만 바꿔 간단히 여러 번 부를 수 있어요.

🖼️ 실행 결과 (235쪽 터틀 실행 결과)

10번의 heart( ) 호출로 찍힌 오렌지색 점들이 모여 8행 × 9열 하트가 돼요.

맨 윗줄은 heart(0,1,2)·heart(0,6,2)로 양쪽에 점 2개씩, 가운데 줄(heart(2,0,9)·heart(3,0,9))은 9개가 꽉 차 하트의 넓은 부분이 돼요.

04

응용 · 미키마우스

교과서 236쪽 · 파일 읽기 · 2차원 리스트 · 0/1 점 이미지

쉽게 말하면그림을 0과 1로 적어 둔 파일(미키마우스.txt)을 읽어, 1이면 검은 점, 0이면 흰 점을 찍어요. 15줄을 2차원 리스트로 저장하고, 행·열 중첩 반복으로 15 × 15 칸을 모두 돌며 점을 찍으면 미키마우스가 나타나요.

🐭 미키마우스 코드 (236쪽 소스 코드) · 읽기용

파일을 readlines( )로 줄 단위로 읽어 2차원 리스트 s에 담고, s[y][x] 값에 따라 점의 색을 정해요. speed('fastest')로 빠르게 그릴 수 있어요.

from turtle import *
f = open('미키마우스.txt')
s = []
for row in f.readlines():       # 줄 단위로 읽어 리스트에 저장
    s.append(list(row.strip()))
penup()
for y in range(15):            # y는 0행부터 14행까지
    for x in range(15):        # x는 0열부터 14열까지
        goto(x * 20, -y * 20)    # 각 점의 위치로 이동
        if s[y][x] == '1':       # 파일 값은 문자이므로 문자로 비교
            color('black')
        else:
            color('white')
        dot(20)                  # 점 그리기

파일에서 읽어 온 값은 숫자가 아니라 문자라서, 비교할 때도 '1'처럼 따옴표를 붙여 문자로 비교해요.

🖼️ 실행 결과 예시 결과

파일의 1이 모여 검은 실루엣을, 0이 흰 바탕을 이뤄 미키마우스가 나타나요. 아래는 15 × 15 격자로 다시 그린 예시 그림이에요.

실제 미키마우스.txt는 교과서 자료실에서 내려받거나 메모장에 직접 15 × 15로 적어 두어요(각 값은 0 또는 1). 위 그림은 그 결과를 짐작할 수 있게 재현한 예시예요.
