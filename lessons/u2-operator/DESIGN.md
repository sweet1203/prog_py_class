**줄인 것·접은 것**
- 비트 연산자(113·114쪽 표Ⅱ-12)·기타 연산자(`in`·슬라이싱)·객체 비교(`is`)는 학습 목표 범위 밖이라 코드 체험에서 제외. 표Ⅱ-13에서는 산술·비교·대입·논리만 골라 실음(순위 번호는 교과서 그대로, 중간 줄 생략 명시).
- 119쪽 「핵심 정리」·성취도 평가 척도표(A~E)는 key3·자기 점검 `chips`로 대체(문장 그대로 베끼지 않음).
- 118쪽 **수행 활동3(복리 계산기)** 완성 코드·정답 실행 결과 값(만기 총금액)은 넣지 않음. 공식 표(A·P·r·n·t)와 입력 4개 틀·힌트만 제시.

**교과서 원문 확인·보정**
- 115쪽 해 보기 1·2·3은 교과서 지면에서 일부 빈칸(`minutes`·`seconds`·`distance` 줄)이라, 소스 코드 파일(`3. 연산자/115쪽_해 보기1~3.py`)의 완성된 형태를 pyrun에 사용함.
- 114쪽 표Ⅱ-13의 논리 연산자 칸은 `not, or, and`로 적혀 있으나, 112쪽 본문은 우선순위를 「논리 부정, 논리곱, 논리합」이라 설명함. 화면에는 본문 기준(not → and → or)으로 표기하고 괄호 사용을 권하는 문장을 덧붙임.
- 115쪽 해 보기 3은 변수명 `id`가 내장 함수 이름과 같지만 교과서 코드 그대로 사용(동작에는 문제 없음).
- 118쪽 출력 예시의 「연이율: 0.04%」는 소수로 바꾼 값을 %로 표시해 의미가 어긋나므로, 화면에는 출력 예시를 싣지 않고 「원금·연이율·기간·복리 횟수·총금액을 출력」으로만 안내함.
