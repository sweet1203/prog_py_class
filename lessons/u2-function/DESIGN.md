**줄인 것·접은 것**
- 146쪽 대화 말풍선 전체와 147쪽 그림Ⅱ-6(주스 함수)은 표지 이야기·첫 카드의 글로 풀어 씀. 149쪽 「함수와 튜플」 만화는 넣지 않음.
- 155쪽 예제 1(`odd_even`)은 코드를 실행 칸에 따로 두지 않고 분류 게임·퀴즈 보기의 함수 이름으로만 사용.
- 157쪽 예제 3(`avg`) 리스트 평균 함수는 분량상 실행 칸 없이 생략(BMI·`op`로 매개 변수·반환값을 다룸).
- 교과서 「주요 개념 정리·성취도 평가」(161쪽)는 문장을 그대로 옮기지 않고 key3와 스스로 점검 `chips`로 풀어 씀.
- 160쪽 수행 활동5(가위바위보)는 정답성 과제라 `determine_winner` 본문을 포함해 완성 코드를 싣지 않음. 함수 이름·역할 틀(`...`)과 설계 메모만 제공.

**확인할 점(교과서 원문 보정)**
- **155쪽 해 보기 1**: 원문 소스가 `tri_area(base, height)`로 호출하지만 변수는 `b`, `h`라서 그대로 실행하면 NameError. 실행 칸에서는 `tri_area(b, h)`로 맞춰 실행하고 화면 주석으로 설명. 실행 결과 예(밑변 6·높이 8 → 24.0)는 교과서 그대로, 칸의 기본 입력은 `6\n4`(→ 12.0).
- **157쪽 해 보기 3(BMI)**: 원문 소스는 주석 위치가 흩어져 있고 `return bmi_result`·`bmi = bmi_cal(h, w)` 줄이 빈칸(완성 과제)이라, 실행 가능하도록 `return`과 호출 줄을 채워 구성(실행 결과 22.04는 165·60에서 확인). 교과서 출력 형식 `%.2f`는 그대로.
- **158쪽 주사위**: 원문에서 `def sel_dice():` 줄이 지면상 빠져 있어 주석(「1부터 6까지의 숫자를 무작위로 출력하는 함수」)에 맞춰 `def sel_dice():`로 복원. `random` 때문에 실행마다 결과가 달라짐을 화면에서 안내.
- **159쪽 재귀 `fac`**: 「종료 조건」/「재귀 호출」 주석 위치가 서로 바뀌어 있고 `if n > 1`에 콜론이 빠져 있음. 코드는 동작하는 형태(`if n > 1:`)로 쓰고 주석을 바른 줄에 배치. 입력 대신 `fac(3)`·`fac(5)` 직접 호출로 구성.
- 153쪽 `lunch_menu` 비교는 교과서처럼 반환값 없음(A: `None` 출력)과 있음(B)을 두 칸으로 나눠 실행. 난수라 메뉴는 실행마다 달라짐.
- 154쪽 인수 개수 오류 예는 `add_number(1, 2, 3)` 한 가지를 실행해 TypeError를 보게 함(교과서 오류 메시지의 함수 이름 `add_numbers`는 오탈자로 보이며, 실제 출력은 실행 환경에 따름).
- 질문폼 링크는 `{{FORM_URL}}` 자리표시(빌드 치환). `course.json`·`forms`는 건드리지 않음 → 총괄이 form(prog-u2-function) 등록 후 build/check.

**지어낸 것(예시 표시)**
- 05 함수 틀의 함수 이름(`get_user_choice`·`get_computer_choice`)은 이해를 돕기 위한 예시. `determine_winner`는 교과서 틀의 이름을 따름.
- 01 분류 게임 항목(`print`·`len`·`sorted`·`abs`는 148쪽 표, `tri_area`·`odd_even`·`dice_game`은 본문 코드), 02 분류 게임의 코드 조각은 교과서 코드에서 따온 것. 06 질문폼 문구는 설계안 흐름에 맞춘 안내.
