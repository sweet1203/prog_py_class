01

함수의 이해와 정의·호출

교과서 147~151·155쪽 · 함수의 필요성, 종류, def, 호출

쉽게 말하면함수는 특정 기능을 하는 코드 묶음이에요. 한 번 정의(만들기)해 두면, 필요할 때마다 이름을 불러 호출(쓰기)할 수 있어요. 호출하면 입력값을 처리해 결과를 돌려줘요.

🍹 함수를 왜 쓸까? (147쪽)

과일을 주스로 만드는 함수에 토마토를 넣으면 토마토주스, 딸기를 넣으면 딸기주스가 나와요. 과일만 바꿔 여러 번 호출하면 되지요. 카드를 눌러 함수를 쓰는 이유를 확인해요.

🧰 함수의 종류 (148~149쪽)

파이썬의 함수는 크게 내장 함수와 사용자 정의 함수로 나뉘어요. 내장 함수는 별도의 정의 없이 언제든 쓸 수 있고, 사용자 정의 함수는 필요한 기능을 직접 만든 함수예요. 알맞은 쪽으로 보내 봐요.

✍️ 함수의 정의와 호출 (150~151쪽)

함수를 정의할 때는 def, 함수 이름, 소괄호 ( ), 콜론 :을 쓰고, 본문은 들여쓰기로 구분해요. 정의한 함수는 이름과 소괄호로 호출해요.

def 함수 이름(매개 변수 1, 매개 변수 2, …):   # 함수 정의
  함수 본문
  return 반환할 값

함수 이름(인수 1, 인수 2, …)                  # 함수 호출

곱셈을 하는 multiply 함수의 흐름(그림Ⅱ-7)을 따라가 봐요.

① 정의def multiply(a, b):
→
② 호출 · ③ 인수 전달multiply(3, 4) → a=3, b=4
→
④ 본문 실행 · ⑤ 반환c = a * b → return c
→
⑥ 원래 흐름으로 복귀반환값 12가 result에 저장

실행해서 12가 출력되는지 확인하고, 인수 3과 4를 다른 수로 바꿔 봐요.

함수는 먼저 정의한 뒤에 호출해야 해요. 코드는 위에서 아래로 읽으므로, 정의하기 전에 호출하면 오류가 나요. 함수 이름은 알파벳·숫자·밑줄(_)로 지을 수 있고, 숫자로 시작할 수 없으며 def·return·if 같은 예약어는 쓸 수 없어요.

02

매개 변수와 반환값

교과서 151~154·157쪽 · 매개 변수, 인수, 반환값, BMI 함수

쉽게 말하면함수가 받는 값이 매개 변수(정의할 때 쓰는 변수), 호출할 때 넘겨 주는 값이 인수예요. 함수가 일을 마치고 돌려주는 값은 반환값이고, return으로 돌려줘요.

📥 매개 변수 (152쪽)

매개 변수가 없는 함수는 정해진 방식으로만 일하고, 매개 변수가 있는 함수는 호출할 때 받은 값으로 일해요. 두 함수를 함께 돌려 비교해 봐요. 마지막 줄의 7을 바꿔 보세요.

📤 반환값 (152~153쪽)

return이 없는 함수는 값을 돌려주지 않아서, 그 결과를 변수에 저장하면 None(값 없음)이 들어가요. 먼저 반환값이 없는 함수예요. 점심 메뉴는 무작위로 뽑혀서 실행할 때마다 달라질 수 있어요.

이번에는 return으로 반환값이 있는 함수예요. 결과가 result에 저장되어 출력돼요.

return은 값을 돌려줄 뿐 아니라 함수를 끝내고 호출한 곳으로 돌아가게 해요.

🔢 여러 값을 한 번에 반환하기 (153쪽)

반환값은 여러 개일 수도 있어요. 두 수를 입력받아 사칙 연산 결과 네 개를 한꺼번에 돌려받아요. 입력값의 두 수를 바꿔 봐요.

🔀 매개 변수와 인수 구분하기 (154쪽 Tip)

정의할 때 쓰는 변수와 호출할 때 넘기는 값을 헷갈리기 쉬워요. 보이는 것이 어느 쪽인지 골라 봐요.

매개 변수 개수와 인수 개수가 다르면 오류가 나요. 매개 변수는 2개인데 인수를 3개 넣어 호출한 코드를 실행해서 오류 메시지를 확인해 봐요.

▶ 직접 해 보기 · 체질량 지수(BMI) (157쪽 해 보기 3)

키와 몸무게를 공백으로 구분해 입력받아 BMI를 구하는 함수예요. map(float, input().split())은 입력을 쪼개 실수로 바꿔 줘요. 입력값의 키와 몸무게를 바꿔 ▶ 실행해 봐요.

03

람다 함수

교과서 149·156쪽 · lambda, 일반 함수와 비교

쉽게 말하면람다 함수는 간단한 계산을 한 줄로 만드는 이름 없는 함수예요. lambda 매개 변수: 표현식으로 쓰고, 표현식의 결과가 곧 반환값이에요. 간단한 연산이나 한 번만 쓸 함수에 알맞아요.

⚖️ def 함수와 lambda 함수 비교 (156쪽)

lambda 매개 변수: 표현식

두 수의 합을 구하는 함수를 def로 만든 것과 lambda로 만든 것을 나란히 놓고 돌려 봐요. 결과가 같은지 확인해 봐요.

람다 함수는 함수를 정의하면서 바로 쓸 수 있어요. add_lambda = lambda x, y: x + y처럼 변수에 담아 이름을 붙여 쓸 수도 있어요.

🔤 문자열도 합칠 수 있어요 (156쪽 예제 2)

숫자뿐 아니라 문자열을 합치는 람다 함수도 만들 수 있어요. 두 문자열 사이에 공백을 넣어 합쳐요. 문자열을 바꿔 실행해 봐요.

▶ 직접 해 보기 · 인사말 만들기 (156쪽 해 보기 2)

이름과 시간대를 받아 인사말을 만들어 주는 람다 함수예요. '김미영'과 '아침'을 내 이름과 '저녁' 같은 말로 바꿔 ▶ 실행해 봐요.

04

함수의 활용 · 함수 조합

교과서 157~159쪽 · 함수 안에서 함수 호출, 재귀 함수 읽을거리

쉽게 말하면큰 프로그램은 기능별로 함수를 나누고, 한 함수 안에서 다른 함수를 불러 조합해서 만들어요. 각 함수가 하나의 일만 맡으면 읽기도 고치기도 쉬워져요.

🎲 주사위 게임 (158쪽 해 보기 4)

두 사람이 주사위를 굴려 높은 수가 나온 사람이 이기는 프로그램이에요. 함수 두 개로 나눴어요.

🎲 sel_dice( )1부터 6까지 숫자를 무작위로 반환
→
🏆 dice_game(두 이름)안에서 sel_dice( )를 두 번 호출하고 승자를 가려 출력

이름 두 개를 입력값에 적어 실행해 봐요. random은 난수를 만들어서 실행할 때마다 결과가 달라져요. 여러 번 실행해 무승부가 나오는지도 확인해 봐요.

dice_game 함수 안에서 sel_dice( )를 호출해 값을 받아 써요. 이렇게 함수 안에서 다른 함수를 불러 쓰면 각 함수가 하나의 일만 하도록 나눌 수 있어요.

📖 읽을거리 · 재귀 함수 (159쪽 정보 더하기)

재귀 함수는 함수 안에서 자기 자신을 호출하는 함수예요. 반복 작업에 쓸모 있지만, 종료 조건을 제대로 정하지 않으면 끝없이 이어질 수 있어 조심해야 해요. 예로 팩토리얼(n! = 1부터 n까지 자연수의 곱)을 구해 봐요.

fac(5)5 * fac(4)
→
fac(4)4 * fac(3)
→
… fac(1)종료 조건 → 1 반환

fac(3)과 fac(5)의 결과를 실행해 확인하고, 괄호 안의 수를 바꿔 봐요. 너무 큰 수(예: 수천)는 넣지 않는 것이 좋아요.

교과서 159쪽 소스 코드는 「재귀 호출」과 「종료 조건」 주석이 서로 바뀌어 적혀 있어요. 코드 동작은 그대로 두고 주석만 알맞은 줄로 맞춰 실었어요. n이 1보다 크면 자기 자신을 다시 호출하고, 1 이하이면 1을 반환하며 멈춰요.

06

마무리

핵심 문장 · 마무리 퀴즈 · 생각 정리 질문폼

함수는 특정 기능을 하는 코드의 모음이다. 한 번 정의(def)해 두고 필요할 때마다 호출하면 코드를 다시 쓰기 쉽고 구조도 간결해진다.
호출할 때 넘기는 인수는 정의할 때 쓴 매개 변수로 전달되고, 함수는 return으로 반환값을 돌려준다. return이 없으면 None이 반환된다.
람다 함수는 lambda 매개 변수: 표현식으로 한 줄로 만들고, 함수 안에서 다른 함수를 불러 조합할 수 있다. 자기 자신을 부르는 재귀 함수에는 종료 조건이 필요하다.
