## 확인할 점
- 교과서 86쪽 해 보기 2의 소스(`input().split()`)는 공백으로 나누므로 취미가 `영화 감상`처럼 띄어쓰기를 포함하면 오류 → stdin 예시는 `홍길동 170 16 영화감상`(띄어쓰기 없음). 화면 캡션에 개수가 맞아야 한다고 안내.
- 86쪽 소스 파일은 `print` 줄이 한 번 더 복제되어 있어(소스 코드 파일 중복) 한 번만 사용. 출력 문구는 소스 파일 기준(`영화 감상`)으로 하고 교과서 결과 표시 `영화감상`과 띄어쓰기만 다름.
- 93쪽 주민등록번호는 교과서 예시 가짜 번호(`101015-1234567`)를 stdin에 넣고, 실제 개인정보를 넣지 말라는 안내를 둠.
- 90쪽 출력 예 중 `d` 줄에 따옴표가 하나 더 찍힌 표기('name is "코난")는 인쇄 오타로 보여 pyrun에는 넣지 않음(`strRun`은 90쪽 연산 코드만 사용).
- 98쪽 교과서 빈칸(`second_hot =`, `min()`)은 소스 파일 기준으로 `avg_temp[-2]`·`min(avg_temp)`로 채워 실행.
- 범위 84~99쪽에는 수행 활동이 없고 「해 보기 1·2·3」만 있음. 95~97쪽 리스트 연산·`range`·`copy`와 컨테이너 자료형 소개의 일부(중첩 리스트의 2차원 표현·배열 정보)는 화면 분량상 다루지 않거나 한 줄로만 언급.
- 교과서 「주요 개념 정리」 문장은 베끼지 않고 바꿔 씀.

## 지어낸 것 (예시 표시)
- 85쪽 코드(`a=10`·`type`) 외에 `type()`으로 자료형을 확인하는 `castRun`(`int/float/str` 전환 후 type 확인)은 교과서 Tip의 자료형 전환 함수를 묶은 확장 예시.
- `selfRun` 뼈대(이름·키·취미 소개 + `type`·`name[0]`)는 86쪽 소개 예를 응용한 연습 틀. 정답 과제 아님.
- `typeGame`의 값 8개(27·-100·3.14·3.2e-5·'100'·'Python'·True·10<20)는 88~90쪽 표의 값 예에서 골라 구성.
- 퀴즈 문항 14개 전부 이 차시용으로 새로 작성(교과서 평가 문항 아님).
- 인덱스 번호표는 91쪽 그림을 표로 다시 그린 것.
