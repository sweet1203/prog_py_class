퀴즈 9문항(3+3+3). 정답 위치 ①3 ②5 ③1(화면에서 학생마다 섞임). 정답이 가장 긴 보기 2/9(22% < 45%). 선택지 극단어 없음, 보기 짧은 것→긴 것.

**화면 수·퀴즈 키 메모** — 설계안 03절이 정한 화면은 「시작 → 01 이해 → 02 표현 → 스스로 해결하기 → 마무리」 **5개(인덱스 0~4)**다. 지시문의 `const QUIZ={1,2,5}`는 본보기(u1-languages, 마무리=5)에서 옮겨 온 표기로 보여, 실제 구조에 맞춰 **개념 2화면 + 마무리에 퀴즈**를 두어 `QUIZ={1,2,4}`로 했다(마무리=인덱스 4). check.py는 QUIZ 키가 화면의 data-quiz와 일치하고 화면 수보다 작으면 통과한다 — data-quiz="1","2","4" / QUIZ 키 1,2,4로 일치.

**50분 흐름(참고)** — 시작(7분) 이야기·일상 속 알고리즘·질문/목표/계획 → 01(16분) 정의·필요성·5조건·노래방 비교·5조건 판정 게임·퀴즈 → 02(16분) 표현 3+1방법·세 표현 tabs(순서도 SVG)·순서도 기호 카드·작성 규칙·퀴즈 → 03(7분) 등교 알고리즘 작성·자기 점검 → 마무리(4분) 퀴즈·질문폼.

**질문폼 근거(prog-u1-algorithm)** — 1번 ← 01 정의·필요성(아파트 도면). 2번 ← 01 5조건·유한성. 3번 ← 02 표현 방법 + 03 등교 알고리즘(`stepWrite` 등). `course.json`·`forms`는 건드리지 않음 → 총괄이 form(prog-u1-algorithm) 등록 후 build/check.

**이미지 대신 다시 그린 것 (지침: 이미지 금지)**
- 그림Ⅰ-14(점수→합격/불합격 순서도)를 **인라인 SVG**로 재현(02 tabs 순서도 탭). 박스 배치는 교과서 그림을 알아보기 쉽게 세로로 재배치, 흐름선 교차 없음.
- 표Ⅰ-5 순서도 기호(터미널·처리·조건·입출력·준비·흐름선·연결자)를 작은 **인라인 SVG 도형**으로 그려 `flipCards`에 넣음(기호 ↔ 뜻).
- 그림Ⅰ-12(조리법)은 사진 대신 .flow2 5단계 흐름으로.
