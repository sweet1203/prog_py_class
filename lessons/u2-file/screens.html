01

파일의 이해

교과서 163~167쪽 · 파일의 개념과 유형, 파일 입출력의 기본 동작

쉽게 말하면파일은 데이터를 저장하는 기본 단위예요. 파일 이름 끝의 확장자(.txt, .jpg …)를 보면 어떤 파일인지 알 수 있어요. 파일은 글자로 된 텍스트 파일과 그렇지 않은 이진 파일로 나눠요.

📁 파일은 어떤 일을 할까? (163쪽 그림Ⅱ-8)

파일에는 숫자나 문자, 그림 같은 정보가 담겨 있어요. 파이썬에서 파일을 만들거나 읽고 쓸 때는 파일의 이름과 확장자, 그리고 경로(파일이 저장된 위치)를 정확히 지정해야 해요.

💾 저장·보관필요할 때 언제든 꺼내 확인하고 활용할 수 있어요.
🛟 백업·복구중요한 데이터를 따로 두어 손실 위험을 줄여요.
📤 공유·전송다른 사람이나 장치로 데이터를 전달해요.
🔐 보안읽기·쓰기·실행 권한을 설정해 데이터를 보호해요.

🗂️ 파일의 유형 (164~165쪽)

저장된 데이터의 방식에 따라 텍스트 파일(사람이 읽을 수 있는 글자)과 이진 파일(숫자·이미지·소리·실행 코드처럼 이진 형태로 저장, 사람이 직접 읽을 수 없음)로 나눠요. 아래 파일을 알맞은 쪽으로 보내 봐요.

🔄 파일 입출력의 기본 동작 (166~167쪽 그림Ⅱ-9)

파일을 다룰 때는 열기 → 읽기·쓰기 → 닫기 순서를 따라요. 카드를 눌러 각 단계를 확인해요.

파일 객체 = open(파일명, 입출력 모드)    # 열기
...                                       # 읽기·쓰기
파일 객체.close()                        # 닫기

파일 객체 · 파이썬에서 파일을 읽고 쓰는 작업을 하려고 쓰는 값이에요. 파일을 닫지 않고 쓰는 도중에 프로그램이 끝나면 데이터가 저장되지 않을 수 있어서, 작업이 끝나면 꼭 닫아요.

02

파일 쓰기와 with문

교과서 167~170쪽 · write( ), writelines( ), 모드 w·a, with문

쉽게 말하면파일에 쓰려면 모드를 'w'(새로 쓰기)나 'a'(이어 쓰기)로 열고 write( )로 내용을 써요. 줄을 바꾸려면 '\n'을 직접 붙여야 해요. with문을 쓰면 닫는 일을 파이썬이 대신 해 줘요.

✍️ 쓰고 바로 읽어 보기 (167~168쪽)

입출력 모드설명
'w'쓰기 모드. 같은 이름의 파일이 있으면 기존 데이터는 삭제되고 새로 만들어요.
'a'추가 모드. 파일이 없으면 새로 만들고, 있으면 기존 내용 뒤에 이어서 써요.

write( )로 한 줄을 쓴 뒤, 같은 칸에서 읽기 모드('r')로 다시 열어 잘 저장됐는지 확인해요. 문장을 바꿔 실행해 봐요.

write( )는 파일에 데이터를 쓰고, writelines( )는 리스트처럼 반복할 수 있는 여러 줄의 데이터를 한 번에 써요.

🔀 'w'와 'a'는 무엇이 다를까? (168쪽)

같은 파일을 쓰기 → 이어 쓰기 → 다시 쓰기 순서로 열고, 매번 내용을 읽어 비교해 봐요. 무엇이 남고 무엇이 지워질지 먼저 예상하고 실행해요.

세 번째 결과가 한 줄만 남은 까닭은 'w'로 다시 열자 이전 내용이 삭제되었기 때문이에요. 이어서 쓰려면 'a'를 써요.

🔒 with문으로 자동으로 닫기 (169쪽)

with open(파일 이름, 입출력 모드) as 파일 객체:
  문장

블록을 벗어나면 close( )가 자동으로 불려요. 닫는 것을 깜빡해 데이터가 사라지는 실수를 막아 줘요. 학생 세 명의 학번과 세 과목 점수를 grade.txt에 저장하고, 마지막에 파일을 읽어 확인해 봐요.

항목 사이에 '\t'(탭)를 넣어 간격을 일정하게 맞췄어요. 줄 끝의 '\n'이 있어야 학생마다 한 줄씩 저장돼요.

💌 해 보기 · 친구에게 편지 쓰기 (170쪽)

입력한 내용을 한 줄씩 파일에 쓰다가, 아무것도 입력하지 않고 Enter를 누르면 끝나는 프로그램이에요. 아래 입력값 칸의 마지막 빈 줄이 「Enter만 누른 것」이라 반복이 끝나요. 입력값을 내 편지로 바꿔 실행해 봐요.

입력값 칸 맨 아래에 빈 줄을 꼭 남겨 두세요. 빈 줄이 없으면 입력이 모자라 오류가 나요.

03

파일 읽기

교과서 171~173쪽 · 'r' 모드, read( )·readline( )·readlines( ), strip( )·split( )

쉽게 말하면파일을 읽으려면 모드를 'r'로 열어요(모드를 쓰지 않으면 읽기 모드예요). 읽는 함수는 read( )(전체), readline( )(한 줄씩), readlines( )(줄 단위 리스트) 세 가지예요.

📖 세 가지 읽기 함수 비교 (171쪽)

함수하는 일
read( )파일 전체 내용을 하나의 문자열로 돌려줘요.
readline( )한 번에 한 줄씩 읽어 돌려줘요.
readlines( )전체를 줄 단위로 읽어 리스트로 돌려줘요(각 줄에 줄 바꿈 문자 포함).

파일을 먼저 만든 뒤 세 방식으로 읽어, 결과가 어떻게 다른지 비교해 봐요.

파일을 읽은 뒤에도 파일을 쓸 때와 마찬가지로 close( )로 닫아요. 한글이 깨지면 encoding='utf-8'이나 encoding='cp949'를 지정해 읽을 수 있어요(171쪽 Tip, 실제 저장된 인코딩에 맞춰야 해요).

✂️ 한 줄을 쪼개는 strip( )과 split( ) (172쪽)

파일에서 읽은 한 줄에는 줄 바꿈 문자가 붙어 있어요. strip( )은 문자열 양끝의 공백을 없애고, split( )은 공백을 기준으로 문자열을 나눠 리스트로 만들어요.

📊 예제 · 학생별 평균 구하기 (172쪽 예제 2)

앞에서 만든 grade.txt를 한 줄씩 읽어 과목별 점수와 평균을 출력해요. 첫 줄(제목)을 먼저 읽고, while line: 안에서 줄을 읽어 처리한 뒤 다음 줄을 다시 읽는 구조예요. 마지막 줄 다음에는 빈 문자열이 읽혀 반복이 끝나요.

이 칸은 파일을 만든 뒤 바로 읽도록 앞부분에 쓰기 코드를 함께 두었어요. 점수를 바꿔 실행하면 평균도 달라져요.

🏅 해 보기 · 프로그래밍 우수자 찾기 (173쪽 해 보기 2)

프로그래밍 점수가 90점 이상인 학생만 골라 출력해요. 조건의 숫자를 바꿔 보고, 정보 점수(inf)가 80점 이상인 학생을 찾도록 고쳐 봐요. 또 with문으로 바꿔도 같은 결과가 나오는지 확인해 봐요.

04

파일 모드 정리 · 이진 파일

교과서 166·171·174·175쪽 · 입출력 모드 한눈에, 이진 파일 처리

쉽게 말하면파일을 열 때 쓰는 모드가 파일로 무엇을 할지 정해요. 글자 파일은 r·w·a, 이진 파일은 뒤에 b를 붙인 rb·wb를 써요.

🗒️ 입출력 모드 한눈에 보기

모드하는 일파일이 없으면
'r'읽기. 모드를 생략하면 읽기 모드예요.오류가 발생해요.
'w'쓰기. 기존 데이터를 삭제하고 새로 써요.새로 만들어요.
'a'추가. 파일 끝에 이어서 써요.새로 만들어요.
'rb'이진 파일 읽기.오류가 발생해요(읽기 모드이므로).
'wb'이진 파일 쓰기.새로 만들어요.

'rb'·'wb'의 「파일이 없으면」 칸은 읽기·쓰기 모드의 일반 규칙을 이어서 정리한 거예요.

🖼️ 이진 파일 읽기 (174쪽 예제 3) · 읽기용

이진 파일은 문자가 아니라 바이트 단위로 처리해서, 열 때 모드에 b를 포함해요. 이미지 파일이 필요해서 이 화면에서는 실행하지 않고 코드와 결과만 읽어 봐요.

# image.bmp를 1바이트씩 5번 읽어 출력
with open('image.bmp', 'rb') as f:
  byte = f.read(1)
  for i in range(5):
    print(byte)
    byte = f.read(1)      # 파일을 한 번에 1바이트씩 읽기
# 실행 결과 — 글자가 아니라 바이트 값이 출력돼요
b'B'
b'M'
b'H'
b'\xe6'
b'\xc3'

read(size)의 size는 읽을 바이트 수예요. read(1)은 1바이트씩 읽고, size를 생략하면 파일 끝까지 읽어요. 반환된 값은 bytes 형식이라 실제 문자열이 아니에요.

📋 이진 파일 복사하기 (175쪽 예제 4) · 읽기용

읽기 모드('rb')로 연 파일의 내용을 쓰기 모드('wb')로 연 새 파일에 써서 복사해요.

copy = input('복사할 파일 이름을 입력하세요: ')
paste = input('붙여넣기할 파일 이름을 입력하세요: ')

data_in = open(copy, 'rb')
data_out = open(paste, 'wb')
byte = data_in.read()
data_out.write(byte)
data_in.close()
data_out.close()
print('복사가 완료되었습니다.')

텍스트 파일은 사람이 읽을 수 있는 데이터를 저장하기에 알맞고, 이진 파일은 이미지처럼 사람이 직접 읽을 수 없는 데이터를 저장하기에 알맞아요. 저장할 데이터의 유형에 맞는 파일 형식을 고르는 게 중요해요.

06

마무리

핵심 문장 · 마무리 퀴즈 · 생각 정리 질문폼

파일은 데이터를 저장하는 기본 단위로, 글자로 된 텍스트 파일과 이진 형태로 저장되는 이진 파일로 나눈다. 파일 처리는 열기 → 읽기·쓰기 → 닫기 순서로 한다.
open( )의 모드로 용도를 정한다. 'w'는 새로 쓰기, 'a'는 이어 쓰기, 'r'은 읽기다. 줄을 바꾸려면 '\n'을 붙이고, with문을 쓰면 파일이 자동으로 닫힌다.
readline( )으로 한 줄씩 읽고 strip( )·split( )으로 나누어 계산하며, 이진 파일은 'rb'·'wb'로 바이트 단위로 읽고 쓴다.
