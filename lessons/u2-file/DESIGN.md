pyrun 9개(helloRun 포함, 실행 칸 총 9). 퀴즈 13문항(2+3+3+2+3). 정답 위치 0·1·2 고르게, 보기 짧은→긴, 극단어 없음.

**pyrun 설계 원칙** — Pyodide 가상 파일시스템이라 한 칸 안에서 파일을 만들고 바로 읽도록 구성(다른 칸의 파일에 의존 안 함). 같은 이름(`example.txt`·`grade.txt`)을 칸마다 새로 써서 서로 영향이 없다. 들여쓰기 공백 2칸.

**질문폼 근거(prog-u2-file)** — 1번 ← 00·01(파일 필요성)·02, 2번 ← 02 waRun·withRun, 3번 ← 05 메모(`paps1~3`).

**교과서에서 바로잡거나 바꾼 것**
- 168쪽 `writelines` 예의 `'\n 10102 …'`(줄 바꿈 뒤 공백)는 실행 결과(173쪽 읽기 출력)와 맞지 않아 `'\n10102 …'`로 정정.
- 168쪽 코드는 닫기를 별도 줄로 보이던 것을 그대로 쓰되, 읽기 확인을 같은 칸에 추가(교과서 외, 확인용).
- 170쪽 `while True` 편지 쓰기: 코드는 그대로, **stdin 끝의 빈 줄**로 종료되게 안내(입력 모자라면 EOFError 안내 문구 포함).
- 172쪽 해결 문제 문구의 「국어」는 표·코드의 「정보」와 달라 화면에서는 「정보·정보과학·프로그래밍」으로 통일. 173쪽 `pro > = 90`의 띄어쓰기 오타는 `pro >= 90`으로.
- 171쪽 readRun은 example.txt를 3줄로 줄여 먼저 만든 뒤 읽음(원본은 168쪽에서 만든 5줄 파일).
- 04 모드 표의 `rb`/`wb` 「파일이 없으면」 칸은 교과서에 명시되지 않아 읽기·쓰기 일반 규칙으로 정리한 것(화면에 note로 밝힘). 166쪽·171쪽·174~175쪽 설명을 한 표로 모음.

**넣지 않은 것**
- 176쪽 수행 활동 6(PAPS) 정답 코드·등급 계산 코드. 교과서 틀 코드도 넣지 않고 과정만 메모.
- 174쪽 이진 파일 `image.bmp`(실제 파일 필요) 실행, 175쪽 이진 복사(파일 이름을 입력받음) 실행 — `<pre class="code">`로만.
- 164~165쪽 CSV·JSON·이미지·오디오·비디오 라이브러리 코드(pandas·PIL·pydub·OpenCV·Colab) — 웹 실행 불가·본 차시 범위 밖. 확장자 분류 게임으로 대체.
- 170쪽 코랩 파일 내려받기 안내(정보 상자), 177쪽 개념 정리 표·평가 문항(교과서 문장 그대로 베끼지 않음).

**지어낸 것(예시 표시)**
