변환기 구현 · file_converter.py

교과서 228쪽 · PDF를 한글·엑셀로 바꾸는 FileConverter 클래스

쉽게 말하면FileConverter는 「파일을 바꿔 주는 기능」을 모아 둔 클래스예요. PDF를 한글 문서(HWPX)로 바꾸는 기능과, PDF 속 표를 찾아 스프레드시트(엑셀)로 저장하는 기능, 두 가지를 담고 있어요.

🔁 파일 변환기 코드 읽기 (228쪽 · 읽기용)

이 코드는 pyhwpx·pymupdf처럼 컴퓨터에 설치해야 도는 라이브러리를 써서 웹에서는 실행하지 않아요. 대신 무엇을 하는 코드인지 주석과 함께 읽어 봐요.

# 필요한 라이브러리 가져오기
import pandas as pd            # 표 데이터를 다루는 라이브러리
import pymupdf                  # PDF를 열고 표를 찾는 라이브러리
from pyhwpx import Hwp          # 한글(HWPX) 변환을 위한 pyhwpx

class FileConverter:            # 파일을 변환하는 기능을 모아 둔 클래스

    @staticmethod
    def convert_to_hwpx(pdf_path, output_path):
        """PDF를 한글 문서 파일로 변환"""
        hwp = Hwp()
        hwp.open_pdf(pdf_path)       # PDF 파일 열기
        hwp.save_as(output_path)     # HWPX 파일로 저장
        return output_path

    @staticmethod
    def extract_tables_to_excel(pdf_path, output_path):
        """PDF에서 표 데이터를 추출해 스프레드시트로 저장"""
        doc = pymupdf.open(pdf_path) # PDF 문서 열기
        all_tables = []              # 표 데이터를 모을 리스트
        for page in doc:             # 페이지를 하나씩 돌며
            tables = page.find_tables()      # 표 찾기
            for table in tables.tables:
                all_tables.extend(table.extract())
        if all_tables:              # 표가 있으면
            df = pd.DataFrame(all_tables)     # 데이터프레임으로 만들고
            df.to_excel(output_path, index=False, header=False)  # 엑셀로 저장
        else:
            print('⚠ 표 데이터가 없습니다.')
        return output_path

메소드 두 개 모두 앞에 @staticmethod가 붙어 있어요. 덕분에 객체를 따로 만들지 않고 FileConverter.convert_to_hwpx(...)처럼 클래스명으로 바로 부를 수 있어요.

화면·실행 구현 · gui.py / main.py

교과서 229쪽 · 사용자 화면(GUI)과 프로그램 실행 시작점

쉽게 말하면gui.py는 사용자가 보고 누르는 화면을 만들어요(버튼·입력칸). main.py는 프로그램을 켜고 화면을 띄우는 시작점이에요. 변환 실행 버튼을 누르면 앞 차시에서 만든 process_handler가 불려 실제 변환이 진행돼요.

🖥️ 화면 코드 읽기 · gui.py (229쪽 · 읽기용)

tkinter는 파이썬에서 창·버튼 같은 화면을 만드는 라이브러리예요. 긴 코드이지만 버튼을 배치하고, 파일·폴더를 고르고, 실행 버튼이 process_handler를 부른다는 큰 흐름만 잡으면 돼요.

import os
import tkinter as tk                 # GUI 제작을 위한 tkinter
from tkinter import filedialog         # 파일·폴더 선택 기능
from process_handler import process_handler  # 변환 총괄 모듈(앞 차시)

class ProcessGUI:
    def __init__(self, root):
        self.root = root
        self.root.title('PDF 변환 프로그램')    # 창 제목
        self.root.geometry('400x310')          # 창 크기
        tk.Button(root, text='📂 원본 PDF 선택', command=self.load_pdf, width=30).pack(pady=5)
        tk.Label(root, text='✏️ 추출할 페이지 입력:').pack()
        self.page_entry = tk.Entry(root, width=10, justify='center')
        self.page_entry.pack(pady=5)
        tk.Button(root, text='📁 저장 폴더 선택', command=self.select_folder, width=30).pack(pady=5)
        tk.Button(root, text='🚀 변환 실행', command=self.run_processing, width=30, bg='lightblue').pack(pady=10)
        self.pdf_path = ''            # 선택한 PDF 경로
        self.save_directory = ''      # 저장 폴더 경로

    def load_pdf(self):             # 변환할 PDF 파일 고르기
        self.pdf_path = filedialog.askopenfilename(filetypes=[('PDF Files', '*.pdf')])

    def select_folder(self):        # 저장할 폴더 고르기
        self.save_directory = filedialog.askdirectory()

    def run_processing(self):       # 변환 실행 버튼을 눌렀을 때
        if (not self.pdf_path or
                not self.page_entry.get().isdigit() or
                not self.save_directory):
            tk.Label(self.root, text='⚠️ 올바른 정보를 입력하세요!', fg='red').pack()
            return
        page_number = int(self.page_entry.get())
        pdf_output, hwpx_output, excel_output = process_handler(
            self.pdf_path, self.save_directory, page_number)  # ← 변환 총괄 호출

command=self.load_pdf처럼 버튼마다 누르면 실행할 기능을 연결해 둬요. 입력이 빠지면 빨간 글씨로 안내하고 멈추는(return) 점도 눈여겨봐요.

📄 실행 시작점 · main.py (229쪽 · 읽기용)

프로그램을 실행하면 가장 먼저 도는 부분이에요. 빈 창을 만들고, 화면을 올린 뒤, mainloop( )로 사용자의 입력을 계속 기다려요.

import tkinter as tk
from gui import ProcessGUI          # 화면 클래스 가져오기

if __name__ == '__main__':
    root = tk.Tk()                   # 비어 있는 창 만들기
    ProcessGUI(root)                 # 화면 구성
    root.mainloop()                  # 이벤트 루프 — 입력을 기다림

mainloop( )는 프로그램이 꺼지지 않고 계속 돌며 버튼 클릭 같은 입력을 기다리게 해요. 그래서 tkinter 프로그램은 웹 실행 칸에서 돌리기 어렵고, 여기서는 읽기용으로 봐요.

변환기(file_converter)는 @staticmethod로 기능을 모아 둔 클래스로, pyhwpx로 PDF를 한글로, pymupdf·pandas로 표를 엑셀로 바꾼다. gui.py는 화면을, main.py는 mainloop( )로 실행을 맡는다.
프로그램이 의도대로 도는지 단위 → 통합 → 시스템 순서로 테스트한다. 파이썬 내장 도구 unittest로 test_ 함수를 자동 실행하며, 발견한 결함을 고치고 다듬는 일이 유지 보수다.
소프트웨어는 기획·요구 분석 → 설계 → 구현 → 테스트·유지 보수 절차로 만든다. 각 단계는 산출물(요구 분석 명세서·설계 명세서·소스 코드·테스트 결과)을 남기며, 문제가 달라도 절차는 같다.
