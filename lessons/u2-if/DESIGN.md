퀴즈 13문항(01·02 각 2, 03·04·마무리 각 3). pyrun 11개(전부 교과서 「해 보기」·예제 코드, 들여쓰기 공백 2칸, 무한 반복 없음).

**50분 흐름(참고)** — 시작(6분) → 01(6분) 순차 구조 → 02(9분) if → 03(11분) if~else, 18·19 경계 → 04(14분) elif, 범위 검사, 점수 순서 → 05(4분) → 마무리(4분).

**질문폼 근거(prog-u2-if)** — 1번 ← 01 페트병(순차)·03 교통 카드(선택), 2번 ← 03 교통 카드 18·19 실행, 3번 ← 04 점수 순서 비교·범위 검사(13). 05 메모(`clubStruct` 등)가 설계 근거.

**줄인 것·접은 것**
- 131쪽(반복 구조·while)은 다음 차시(u2-loop) 범위라 넣지 않음. 120·121쪽의 반복 구조는 개념 한 줄로만 소개.
- 124쪽 NS 차트는 순서도(판단 기호 ◇) 인라인 SVG로 바꿔 보여 줌. 123쪽 「정보」 일상 순차 예시 그림, 130쪽 「정보」 선택 구조 일상 예시 그림은 생략.
- 129쪽 「정보」 예외 처리(`try ~ except ~ finally`)는 이름만 소개(callout), 실행 칸 없음.
- 교과서 「주요 개념 정리」·성취도 평가 문장은 베끼지 않고 key3·chips로 새로 씀.

**확인할 점**
- **125쪽 시차 코드**: 교과서 지면 소스는 시차 계산 줄(`france_hour = hour - 7`)이 빠져 있고, 제공 소스 파일(`125쪽_해 보기.py`)에는 있음. pyrun은 소스 파일 기준으로 실행(3시 30분 → 프랑스 20시 30분, 17시 → 10시).
- **129쪽 계절식 `month // 3`**: 봄은 3~5월(몫 1), 여름 6~8월(몫 2), 가을 9~11월(몫 3)이고, 12월(몫 4)·1·2월(몫 0)은 모두 else로 가서 겨울. 3·6·9·12월에서 계절이 바뀌는 방식을 직접 실행해 확인했고(0~13월 몫 표 일치), 캡션과 표로 「월을 3으로 나눈 몫으로 계절을 나눈 방식」임을 설명. 이 식은 1~12 밖(13 등)도 겨울로 처리하므로 129쪽 해 보기 4의 범위 검사가 필요함을 04에서 연결.
- **129쪽 해 보기 4**: 교과서 지면은 빈칸 틀, 소스 파일은 완성본(`if 12 < month or month < 1:`). 소스 파일 기준으로 실행(해 보기이며 수행 활동 아님).
- 130쪽 지면 소스는 추출 과정에서 elif 줄이 일부 빠져 있어, 소스 파일(`130쪽_해 보기.py`)의 `if ~ elif ~ elif ~ elif ~ else` 구조를 따름.
- 127쪽 교통 카드는 `age <= 18`이 청소년이므로 경계값 18은 if 쪽, 19는 else 쪽(실행해 확인).
- 124쪽 Tip의 들여쓰기 일반 4칸 vs 교과서 2칸: 화면은 교과서 방식 공백 2칸으로 통일.

**지어낸 것(예시 표시)**
- 04 「조건 순서를 바꾸면?」 pyrun은 130쪽 Tip을 확인하도록 점수 코드의 조건 순서만 뒤집은 것(교과서 코드를 고쳐 쓴 예시).
- 05 `sorter` 6장의 상황 문장은 교과서 예제(124·125·126·127·128·130쪽)를 짧게 풀어 쓴 것. 코딩 동아리 가입 조건(메모 안내의 「나이」 예)은 보기용으로, 120쪽에는 구체 조건이 없음.
- 02·03 SVG 순서도의 배치는 표Ⅱ-14~16 NS 차트를 순서도 형태로 옮긴 도식.
