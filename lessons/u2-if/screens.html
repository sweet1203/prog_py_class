01

제어 구조와 순차 구조

교과서 121·123쪽 · 순차 구조, 선택 구조, 반복 구조

쉽게 말하면프로그램이 어떤 순서로 실행되는지를 정하는 틀을 제어 구조라고 해요. 위에서 아래로 차례대로 가면 순차, 조건에 따라 길이 갈리면 선택, 같은 일을 되풀이하면 반복이에요.

🧭 제어 구조의 세 가지 (121쪽)

➡️ 순차 구조프로그램 명령을 순서에 따라 차례대로, 한 방향으로 진행해요. (처리 1 → 처리 2 → 처리 3)
🔀 선택 구조주어진 조건이 참이냐 거짓이냐에 따라 실행하는 내용이 서로 달라요. 오늘 중심이에요.
🔁 반복 구조조건을 만족하는 동안 특정 부분을 여러 번 반복해 실행해요. 다음 시간에 만나요.

교과서는 로봇 청소기로 예를 들어요. 전체 작동 과정(거실 → 안방 → 충전소)은 순차, 카펫을 만나면 터보 모드로 바꾸는 부분은 선택, 벽을 만날 때까지 전진하는 부분은 반복이에요.

▶ 직접 해 보기 · 순차 구조 (123쪽 해 보기 1)

투명 페트병을 모으면 개당 300원을 주는 프로그램이에요. 위 줄부터 한 줄씩 차례대로 실행돼요. 입력값 칸의 개수를 바꿔 ▶ 실행해 봐요.

어떤 값을 넣어도 같은 줄이 같은 순서로 실행돼요. 길이 갈리지 않아서 순차 구조예요. 입력에 따라 다른 문장을 실행하려면 선택 구조가 필요해요.

02

if 문

교과서 124·125쪽 · 조건이 참일 때만 실행

쉽게 말하면if는 「만약에 ~라면」이에요. 조건식이 참이면 아래 문장을 실행하고, 거짓이면 그냥 지나가요. 조건식 끝에 콜론( : ), 실행할 문장은 들여쓰기가 필요해요.

🔀 if 문의 모양 (표Ⅱ-14)

if 조건식:
  처리 1   # 참일 때만 실행
  • 콜론( : ) · if 조건식 끝에 꼭 붙여요.
  • 들여쓰기 · 참일 때 실행할 명령은 들여써요. 들여쓰지 않으면 오류가 나요. 여러 줄이면 모두 같게 들여써요.
  • 이 교과서는 공백 2칸으로 들여써요.

▶ 나이가 18세 이상이면 (124쪽)

18세 이상일 때만 「성인입니다.」를 출력해요. 입력값을 18에서 17로 바꿔 두 번 실행해 비교해 봐요. 거짓일 때는 아무것도 출력되지 않아요.

▶ 정수가 0보다 크면 ok (125쪽 예제 2)

들여쓴 print('ok')은 조건이 참일 때만, 들여쓰지 않은 print('end')는 언제나 실행돼요. 입력값을 1, 0, -3으로 바꿔 보며 ok가 나오는지 확인해요.

▶ 자동 시차 계산기 (125쪽 해 보기 2)

우리나라 시간에서 7을 빼면 프랑스 시간이에요. 그런데 3시 − 7 = −4처럼 음수가 되면 24를 더해 바로잡아요. 시간을 3에서 17로 바꿔 실행해 보고, 어느 경우에 if 안쪽이 실행되는지 찾아봐요.

시간이 3일 때는 france_hour가 −4가 되어 조건이 참, 17일 때는 10이라 거짓이에요. 거짓이면 france_hour += 24는 건너뛰어요.

03

if ~ else 문

교과서 126·127쪽 · 참이면 처리 1, 거짓이면 처리 2

쉽게 말하면조건이 참이면 한 가지를, 거짓이면 다른 가지를 실행해요. 두 갈래 중 하나만 실행되고, if와 else의 들여쓰기 위치는 같아야 해요.

🔀 if ~ else 문의 모양 (표Ⅱ-15)

if 조건식:
  처리 1   # 참일 때
else:
  처리 2   # 거짓일 때

조건식은 비교 연산자나 논리 연산자로 만들고, 결과는 참(True) 또는 거짓(False)이에요. else 뒤에는 조건식을 쓰지 않고 콜론만 붙여요.

▶ 짝수일까, 홀수일까 (126쪽 예제 3)

2로 나눈 나머지가 0이면 짝수예요. 입력값을 7에서 10으로 바꿔 실행해 봐요.

▶ 윤년 판별 (127쪽 예제 4)

조건식에 비교·논리·나머지 연산자가 함께 쓰여요. 연도를 2028, 2026, 2100, 2000으로 바꿔 가며 결과를 확인해 봐요.

4로 나누어 떨어져도 100으로 나누어 떨어지면 윤년이 아니고, 400으로 나누어 떨어지면 윤년이에요. 그래서 2100은 윤년이 아니고 2000은 윤년이에요.

▶ 교통 카드 종류 알려 주기 (127쪽 해 보기 3)

18세 이하는 어린이/청소년 카드, 그 밖은 성인 카드가 발급돼요. 경계값인 18과 19를 차례로 넣어 어느 쪽이 실행되는지 비교해 봐요.

18은 age <= 18이 참이라 if 쪽, 19는 거짓이라 else 쪽이에요. 조건이 갈리는 경계 값은 꼭 확인해 봐요.

04

if ~ elif ~ else 문

교과서 128~130쪽 · 여러 갈래로 나누기

쉽게 말하면갈래가 셋 이상이면 elif(else if)를 이어 붙여요. 조건은 위에서부터 차례로 확인하고, 처음 만난 참에서 그 부분만 실행한 뒤 끝나요. 모두 거짓이면 else가 실행돼요.

🔀 if ~ elif ~ else 문의 모양 (표Ⅱ-16)

if 조건식 1:
  처리 1
elif 조건식 2:
  처리 2
else:
  처리 3
  • elif는 여러 개 쓸 수 있고, else는 생략할 수 있어요.
  • if, elif, else 끝에는 콜론( : )을 붙이고 들여쓰기 위치를 맞춰요.

▶ 월을 입력하면 계절은? (128쪽 예제 5)

월을 3으로 나눈 몫(month // 3)으로 계절을 나눠요. 입력값을 3, 5, 6, 8, 9, 11, 12, 1, 2로 바꿔 가며 어떤 계절이 나오는지 확인해 봐요.

월month // 3출력
3 · 4 · 51봄
6 · 7 · 82여름
9 · 10 · 113가을
12 · 1 · 24 · 0 · 0겨울(else)

몫이 1, 2, 3인 달만 조건에 걸리고, 나머지는 모두 else로 가서 겨울이 돼요. 그래서 겨울은 12월부터 2월까지 한 해 끝과 처음이 이어져요.

▶ 잘못된 입력 막기 (129쪽 해 보기 4)

위 코드에 13이나 −1을 넣으면 겨울이 나와 버려요. 1~12 밖의 값을 먼저 걸러 내는 조건을 맨 앞에 더했어요. 입력값을 13, 0, 12로 바꿔 비교해 봐요.

13 // 3은 4라서 앞의 조건에 모두 걸리지 않고 else로 가요. 범위를 확인하는 조건을 맨 앞에 두면 잘못된 값이 계절로 처리되지 않아요.

▶ 점수로 성취도 알아보기 (130쪽 해 보기 5)

90 이상 A, 80 이상 B, 70 이상 C, 60 이상 D, 그 밖은 F예요. 입력값을 95, 85, 70, 59, 90으로 바꿔 보며 경계 값에서 어떻게 달라지는지 봐요.

🔬 조건 순서를 바꾸면? (130쪽 Tip 확인)

같은 조건을 작은 수부터 물어보도록 순서만 바꿨어요. 95점을 넣으면 어떤 결과가 나올지 먼저 예상한 뒤 실행해 봐요.

95는 맨 위의 >= 60에서 이미 참이라 D가 나오고 아래 조건은 확인하지도 않아요. 이상·초과 조건은 큰 수부터 물어야 하고, 이하·미만 조건은 작은 수부터 물어보는 것이 알맞아요.

💡 예외 상황 처리 (129쪽 정보) 문법이 맞아도 숫자가 아닌 값을 입력하면 실행 중 오류가 나서 멈출 수 있어요. 파이썬은 try ~ except ~ finally로 이런 상황을 미리 대비해 안정적으로 실행하게 해요. 이번 시간에는 이름만 알고 넘어가요.

마무리

핵심 문장 · 마무리 퀴즈 · 생각 정리 질문폼

제어 구조에는 순차(차례대로), 선택(조건에 따라), 반복(여러 번)이 있다. 선택 구조는 조건이 참이냐 거짓이냐에 따라 실행하는 문장이 달라진다.
조건이 참일 때만 할 일이 있으면 if, 두 갈래면 if ~ else, 세 갈래 이상이면 if ~ elif ~ else를 쓴다. 조건식 끝에는 콜론( : )을 붙이고 실행할 문장은 들여쓴다.
조건은 위에서부터 차례로 확인하고 참인 곳 하나만 실행한다. 이상·초과 조건은 큰 수부터, 범위를 벗어난 입력은 맨 앞에서 먼저 걸러 낸다.
