05

마무리

핵심 문장 · 개념 퀴즈 · 생각 정리 질문폼

실습은 입력 → 처리 → 출력 틀을 먼저 그린 뒤, 필요한 개념(난수·반복·자료 구조·함수)을 골라 코드로 옮긴다.
정렬은 값 비교와 교환(a, b = b, a)을 반복하고, 이진 탐색은 가운데 값과 비교해 범위를 절반씩 줄인다.
random 모듈의 randint·shuffle·choice는 문제 출제, 자리 배치, 추천, 비밀번호처럼 무작위가 필요한 곳에 쓰고, 목록은 리스트·딕셔너리에 담는다.
