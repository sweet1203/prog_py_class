**확인할 점**
- VSCode에서 Python 확장을 설치하기 **전에** 파이썬 인터프리터가 운영체제에 설치돼 있어야 함(50쪽 Tip). → `sorter` 1단계를 ‘파이썬 설치’로 두고, 설계안 힌트(다운로드→설치→확장→파이썬 환경)보다 교과서 순서를 따름.
- 로컬 IDE 단점(무거움)·클라우드 IDE 장점(설치 불필요·협업)은 교과서 47~48·51쪽 그대로. 로컬에 VSCode·Thonny, 클라우드에 코랩·리플릿 예시도 교과서에 나온 것만 씀.
- 디버깅 SVG의 박스 배치·화살표는 그림Ⅰ-22를 알아보기 쉽게 재배치한 도식(실제 내부 구조가 아니라 흐름을 보여 줌). ‘소스 코드 수정’ 되돌이 화살표로 반복을 표현.
- 교과서 표기 오타(‘Intergrated’)는 바른 표기(Integrated)로 적음.
- 교과서 쪽 표기는 (47쪽)처럼 참고로만, 차시 번호·날짜·주소 미기재. 질문폼 링크는 `{{FORM_URL}}` 자리표시(빌드 치환). `course.json`·`forms`는 건드리지 않음 → 총괄이 form(prog-u1-dev-env) 등록 후 build/check.
