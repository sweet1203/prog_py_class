현아와 은호의 모둠 과제 이야기 (46쪽)
현아와 은호는 모둠 과제로 프로그램 개발 프로젝트에 도전해요. 현아는 「나는 파이썬으로 프로그램을 개발하고 싶은데, 어떤 개발 환경이 가장 적합할까?」, 은호는 「협업해서 개발하는 게 어때? 개발할 영역을 나눠 만들고 서로 병합하면 좋지 않을까?」라고 말해요. 좋은 프로그램을 만들려면 먼저 어디서 어떤 도구로 만들지를 정해야 해요.

오늘은 프로그램을 만드는 데 필요한 개발 환경이 무엇이고, 통합 개발 환경(IDE)이 왜 편리한지, 그리고 로컬·클라우드 IDE를 어떻게 고르고 준비하는지 살펴봐요.

오늘의 목표 · 4. 프로그램 개발 환경 (46~47쪽)

프로그램을 효율적으로 개발하려면 최적의 개발 환경을 선택해야 해요. 프로젝트에 맞는 도구를 골라 환경을 구축하면, 코드를 작성·실행·수정하는 일이 훨씬 수월해져요. 오늘은 개발 환경이 무엇으로 이루어지는지 알아보고, 통합 개발 환경(IDE)을 골라 준비하는 방법을 배워요.

01

개발 환경의 이해

교과서 47~48쪽 · 개발 과정과 디버깅, 개발 환경의 구성 요소

쉽게 말하면프로그램을 만드는 일은 코드만 적는 게 아니에요. 코드를 쓰고(에디터), 기계어로 바꾸고(번역 프로그램), 오류를 찾아 고치는(디버거) 여러 도구가 필요해요. 이런 도구와 시스템을 갖춘 작업장이 개발 환경이에요.

🧰 개발 환경이란? (47쪽)

개발 환경은 코드 작성, 실행, 디버깅, 배포 등을 원활하게 수행할 수 있도록 지원하는 다양한 도구와 시스템을 포함해요. 프로그래밍은 단순히 코드를 입력하는 코딩 작업을 넘어, 여러 단계를 거치는 복합적인 과정이에요.

🐞 프로그램 개발 과정과 디버깅 (47쪽 그림Ⅰ-22)

알고리즘을 설계하고 코드를 작성한 뒤, 소스 코드를 기계어로 바꿔 실행 파일을 만들어요. 이때 생기는 오류를 추적·수정하는 디버깅을 반복해 프로그램이 완성돼요. 버튼을 눌러 단계를 하나씩 밝혀 봐요.

디버깅 · 프로그램에서 발생하는 오류(버그)를 추적하고 수정하는 과정이에요. 오류가 없을 때까지 디버깅을 반복해요.

🃏 개발 환경을 이루는 도구 (47~48쪽)

카드를 눌러 각 도구가 하는 일을 확인해요. 뜻을 먼저 떠올려 본 뒤 뒤집으면 더 잘 외워져요.

02

통합 개발 환경 구축

교과서 48~53쪽 · 로컬·클라우드 IDE, VSCode·구글 코랩

쉽게 말하면도구를 각각 따로 쓰기보다 하나로 묶은 통합 개발 환경(IDE)을 쓰면 편해요. IDE는 내 컴퓨터에 설치해 쓰는 로컬 환경과, 웹 브라우저로 접속해 쓰는 클라우드 환경으로 나뉘어요. 각각 장단점이 있어 목적과 상황에 맞게 골라요.

🧩 통합 개발 환경(IDE)은 왜 쓸까? (47쪽)

개발자는 코드 편집기, 번역 프로그램, 오류 수정 프로그램 등 다양한 도구를 써요. 이 도구들을 각각 따로 쓰기보다 하나로 통합하면 편리하고 개발 속도도 빨라져요.

통합 개발 환경(IDE, Integrated Development Environment)에디터, 컴파일러, 인터프리터, 디버거 등 프로그램 개발에 필요한 개별 프로그램을 하나로 통합하여 제공하는 소프트웨어 개발 프로그램이에요.

💻☁️ 로컬 환경 vs 클라우드 환경 (47~48쪽 그림Ⅰ-23·24)

통합 개발 환경은 도구와 자원이 어디에 있느냐에 따라 로컬 환경과 클라우드 환경으로 나뉘어요. 버튼을 눌러 비교해 봐요.

🛠️ 로컬 IDE 구축하기 · VSCode 설치·설정 (49~50쪽)

로컬 IDE 중 비주얼 스튜디오 코드(VSCode)는 가볍고 빠르며, 확장(extension) 프로그램으로 원하는 언어와 기능을 더해 개발 환경을 구성할 수 있어 최근 많이 쓰여요. 아래 순서로 준비해요.

  1. 운영체제에 파이썬 인터프리터 설치

    파이썬 공식 사이트에서 설치 파일을 받아 설치해요. 설치 중 ‘Add python.exe to PATH’ 옵션을 체크해요. (VSCode에서 Python 확장으로 개발하려면 이 과정이 먼저 필요해요.)

  2. VSCode 설치 프로그램 다운로드

    VSCode 공식 홈페이지에 접속해 내 운영체제에 맞는 설치 프로그램을 다운로드해요.

  3. VSCode 설치

    다운로드한 파일을 실행하여 설치해요.

  4. 한국어 패키지 설치

    왼쪽 확장(Extensions) 탭을 열고 ‘한국어’를 검색해 설치하면 메뉴 가독성이 높아져요.

  5. Python 확장 설치

    확장 탭에서 ‘python’을 검색해 마이크로소프트의 Python 확장을 설치해요. VSCode에는 파이썬이 내장돼 있지 않아 이 확장이 필요해요.

  6. 코드 작성·실행 확인

    파일(File) > 새 파일(New File)에서 ‘Python File’을 골라 .py로 저장하고, ‘실행 및 디버그’ 또는 터미널로 실행해 결과를 확인해요.

터미널에서 파일을 찾지 못한다는 오류([Error2])가 나면, Python 확장 설치 여부와 .py 파일의 경로·파일명을 확인하고 다시 실행하면 돼요. · 50쪽의 VSCode 설치 영상·QR은 「선생님 자료」로 안내돼요.

🎯 설치 순서 맞히기 (49~50쪽)

아래 할 일이 어느 단계에서 하는 일인지 골라 봐요. VSCode로 파이썬 개발 환경을 준비하는 순서를 떠올려요.

☁️ 클라우드 IDE 구축하기 · 구글 코랩 (51~53쪽 그림Ⅰ-27)

구글 코랩(Colab)은 대표적인 클라우드 기반 IDE예요. 웹 브라우저만으로 개발할 수 있어 별도의 도구를 설치할 필요가 없고, 구글 계정으로 로그인하면 바로 시작할 수 있어요.

  1. 구글 계정으로 로그인

    코랩을 쓰려면 먼저 구글 계정에 로그인해요.

  2. 새 노트북 만들기

    상단 메뉴에서 ‘파일’ → ‘Drive의 새 노트북’을 클릭해 새 노트북을 만들어요. 파일은 자동으로 .ipynb 확장자로 구글 드라이브에 저장돼요.

  3. 코드 셀에 작성·실행

    코드 셀에 코드를 적고, 셀 왼쪽의 실행(▶) 버튼이나 Ctrl+Enter로 실행해요. 결과가 셀 아래에 표시돼요.

코랩은 주피터 노트북과 비슷한 환경이에요. 카드를 눌러 코랩의 네 가지 기능을 확인해요.

주피터 노트북 · 웹 브라우저에서 코드 셀 단위로 실행하는 대화형 파이썬 개발 환경. · 마크다운 · 일반 텍스트로 서식 있는 문서를 쉽게 작성하는 경량 마크업 언어로, HTML 태그로 변환돼 브라우저에 출력돼요.

🤖 구글의 인공지능 서비스, 제미나이(Gemini) (53쪽 「정보」) 구글 코랩에서는 생성형 AI 서비스 제미나이(Gemini)로 코드 작성을 도움받을 수 있어요(만 18세 이상 구글 계정·로그인 필요). 코드에 오류가 날 때 ‘오류 설명’ 버튼으로 수정을 도움받을 수도 있어요. 다만 생성형 AI가 만든 코드가 정답은 아니므로, 쓰기 전에 꼭 직접 분석하고 검토해야 해요.

마무리

핵심 문장 · 마무리 퀴즈 · 생각 정리 질문폼

개발 환경은 코드 작성·실행·디버깅·배포를 돕는 여러 도구와 시스템이다. 프로그램은 알고리즘 설계 → 코드 작성 → 번역(컴파일러/인터프리터) → 실행 과정을 거치며, 오류를 추적·수정하는 디버깅을 반복해 완성된다.
에디터·번역 프로그램·디버거 같은 개별 도구를 하나로 통합한 소프트웨어가 통합 개발 환경(IDE)이다. 따로 쓰기보다 통합해 쓰면 편리하고 개발 속도가 빨라진다.
IDE는 도구와 자원의 위치에 따라 로컬 환경(내 컴퓨터에 설치 · VSCode 등)과 클라우드 환경(웹 브라우저로 접속 · 구글 코랩 등)으로 나뉜다. 목적·시스템 환경·협업 여부를 고려해 적절히 고른다.
